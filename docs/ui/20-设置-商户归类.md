# 20 · 设置 · 商户归类

确认账单后学到的“商户关键字 → 分类 / 账户 / 方向”规则列表。支持单条删除与清空全部。

源码：`app/src/main/java/com/controleco/app/ui/settings/SettingsMerchantRulesScreen.kt`（约 209 行）
共享：`SettingsLazyPage`、`SettingsSection`（未用）、`SettingsPane`、`SettingsDivider`、`EcoConfirm`

---

## 1. 路由与入口

- 路由：`settings/merchantRules`。
- 进入：设置首页 → `自动记账` →「商户归类」。
- 离开：返回。
- 清空：右上「清空全部」→ `EcoConfirm`。

## 3. 页面骨架

```
SettingsLazyPage(micro="MERCHANT RULES", title="商户归类", onBack)
  item header:
    Row("N 条已学规则，最近在前" + 清空全部（N）)
  item list:
    if empty SettingsPane { EcoEmpty("还没有学到的归类") }
    else SettingsPane { MerchantRuleRow + SettingsDivider }
  item (空)
if (clearAsk) EcoConfirm("清空商户归类")
```

## 5. 状态与数据流

### 只读

- `merchantRules`（已是最近在前；页面再按 `updatedAt desc` 兜底排序）。
- `categories`、`accounts`：用于把 id 映射成名称。

### 名称兜底

- 分类缺失 → `已删除分类`。
- 账户缺失 → `已删除账户`；`accountId == null` → 不显示账户段。

### 删除

- 单条：`vm.deleteMerchantRule(rule.id)`，**无二次确认**。
- 清空：`EcoConfirm(danger=true)` → `vm.clearMerchantRules()`。

### 清空文案

`只清除学习到的规则，不影响已入账的账单。之后确认账单会重新开始学习。`

## 9. 坑与验收

**坑**

1. **不能把 LazyColumn 嵌进 `SettingsPage` 的 `verticalScroll`**：旧实现会因无限高度约束崩溃。本页必须用 `SettingsLazyPage`，规则行放在同一个 item 的普通 `Column` 里。
2. 规则行本身不是 Lazy item；不要再为每行包 `LazyColumn`。
3. 单条删除没有确认；清空才有。不要给单条加弹窗改变手感。
4. 规则可能指向已删除的分类/账户；必须显示兜底文案，不能空白或崩溃。
5. 命中次数是累计值，不是本次；不要显示成“最近命中”。
6. 清空只清规则，不影响已入账账单；文案要保留。
7. 页面末尾有一个空 `item {}`；它只是占位/间距，不要误删后改变底部留白（如需删除请确认 `SettingsLazyPage` 的底部 padding）。

**验收**

- [ ] 空态/非空都正常，规则按更新时间倒序。
- [ ] 关键字、方向、分类、账户、命中次数、时间完整。
- [ ] 已删除分类/账户有兜底文案。
- [ ] 单条删除即时生效；清空有二次确认且不影响账单。
- [ ] 规则很多时页面可滚，不崩。
- [ ] 1.25 字体下关键字/详情/删除不挤。
