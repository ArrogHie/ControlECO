# 01 · 应用外壳与导航

这一页不是业务页面，而是所有页面共同的“舞台”：Activity、主题、路由、四 tab、底部栏、FAB、转场、全局弹窗。改业务页通常不需要动它；动它之前必须确认不影响 4 个 tab 和 19 条路由。

源码：

- `app/src/main/java/com/controleco/app/MainActivity.kt`
- `app/src/main/java/com/controleco/app/ui/AppNav.kt`
- `app/src/main/java/com/controleco/app/ui/eco/EcoScaffold.kt`（`EcoBottomNav` / `EcoFab` / `ecoBottomContentPadding` / `EcoToastHost`）
- `app/src/main/java/com/controleco/app/ui/common/PermissionReminderDialog.kt`

## 1. 路由与入口

| 路由 | 进入方式 | 页面 |

| `edit/{txId}` | 账单点击、捕获通知、溯源“查看对应账单” | 编辑交易 |
| `accounts` | 个人页账户、设置账户入口 | 账户管理 |

| `captureTrace` | 设置 → 开发者功能 | 记账溯源 |

| `settings/account` | 个人页账户卡 | 账户入口 |
| `settings/import` | 个人页导入卡 | 账单导入说明 |

| `settings/watchedApps` | 设置 → 自动记账 | 监听的 App |
| `settings/merchantRules` | 设置 → 自动记账 | 商户归类 |
| `settings/developer` | 设置 → 系统、调试直达 | 开发者功能 |
| `settings/about` | 设置 → 关于 | 关于 |
| `keepAlive` | 设置 → 开发者功能 | 保活与自启动 |

通知/外部入口（`LaunchedEffect(navEvent.first)`）：

- `CaptureCenter.ROUTE_PENDING` → `pending`
- `ROUTE_REFUND_LINK` → `refundLink`
- `ROUTE_EDIT_PREFIX + id` → `edit/{id}`
- `quickAdd` → `quickAdd`
- `settings/developer` / `settings/permissions` → 直达
- `ROUTE_OVERLAY_TEST` → 直接 `CaptureCenter.showOverlayTest(...)`，不落库、不导航
- `ROUTE_IMPORT_FILE_PREFIX + uri` → 先 `vm.parseBillFile(uri)` 再进 `import`

**路由名是通知契约，不要改。**

## 3. 从上到下的外壳骨架

```
MainActivity
  AccBookTheme(AccentThemeStore.current)
    Box(fillMaxSize)
      AccBookNav(vm, navEvent, promptPermissions)
        Box(fillMaxSize)
          EcoBackdrop()                    // 全局纸面
          NavHost(...)                     // 当前路由页面
          EcoToastHost(bottom = 112dp)     // 浮在最上
        PermissionReminderDialog(...)      // 与 NavHost 并列
      UpdateAvailableDialog()              // 最外层，系统对话框

MainScaffold(tab)
  Box(fillMaxSize)
    for (i in 0..3) if (i == tab || i == previousTab)   // 固定 key 占位，旧页不重建
      key(i)
        Box(zIndex = if (i == tab) 1 else 0,
            graphicsLayer: alpha = if (i == tab) pageIn else previousAlpha,
            blockPointerInput() 仅旧页)                  // 旧页可见但不响应触摸
          SaveableStateProvider(i)
            TabPage(i)                                  // 0 Home / 1 TransactionList / 2 Stats / 3 Profile
    EcoBottomNav(align BottomCenter)
    AnimatedVisibility(visible = tab == 0 || tab == 1)
      EcoFab(align BottomEnd, end=19, bottom=ecoFabBottomOffset())
```

关键点：

- 四个 tab 的内容**互斥**，不是横向 pager。切 tab 时**旧页保留一帧层作底图**，新页在它上面 260ms 淡入 + 8dp 上移；动画结束（`pageIn` 到 1）才释放旧页。
  这样任何一帧都有完整内容，不会出现“旧页消失 → 纸面露出来 → 新页淡入”的闪白。
- 每个 tab 用**固定 key**（`key(i)` + `SaveableStateProvider(i)`）占位：切走后旧页仍在树上，只是退到底层，
  因此**不会被重建**——滚动位置、`rememberSaveable`、入场动画都不会重播；也避免同一 key 的
  `SaveableStateProvider` 在一帧内出现两份而丢状态。
- 旧页底图必须套 `blockPointerInput()`：在 `PointerEventPass.Initial` 消费全部触摸，否则旧页的
  `pointerInput` 会挡住新页点击；旧页同时 `zIndex = 0`、新页 `zIndex = 1`，保证命中顺序确定
  （`AnimatedContent` 时代踩过的坑）。
- `pageIn` 用 `remember(tab) { Animatable(...) }` 创建：**首帧即目标值**。旧写法 `remember { Animatable(1f) }` + `LaunchedEffect(tab)` 里 `snapTo(0)` 会让新页先以全不透明画一帧再归零，这一帧就是“闪一下”。
- `previousAlpha` 记录旧页切走瞬间的透明度：快速连点时不把它强行拉回 1，避免闪亮。
- alpha 在 `graphicsLayer` 的 draw 块里读取，动画每帧只失效图层，不重组整页。
- 首次进入（`hasSwitched == false`）`pageIn` 初值为 1，启动时不再重播淡入。
- FAB 只在 tab 0/1 出现，用 `AnimatedVisibility` 淡出+缩小，避免切换瞬间突兀消失。
- 底部栏永远 overlay，不参与内容测量。

## 5. 状态与数据流

`AccBookNav` 持有：

- `permissionMissing: List<PermissionKind>`：冷启动时 `CapturePermissions.claimLaunchPrompt()` 返回的缺失权限；展示后清空。
- `vm: LedgerViewModel`：Activity 级 `viewModel()`，所有页面共享同一实例。
- `navEvent: Pair<Long, String?>`：Activity 自增序号 + route，保证同一路由重复点击也能触发。

`MainScaffold` 持有：

- `tab: Int`（`rememberSaveable`，0–3）。
- `reenterTick: Int`（再次点当前 tab 时 +1），传给账单/统计用于回顶。
- `previousTab: Int?`：切 tab 时的旧页，作为过渡底图；动画结束置空。
- `previousAlpha: Float`：旧页切走瞬间的透明度，快速连点时避免它被强行拉回 1 而闪亮。
- `hasSwitched: Boolean`：区分“启动首帧”和“切 tab”，首帧不播淡入。
- `pageIn: Animatable`：`remember(tab)` 创建，首帧即目标值；只在切 tab 时 0→1。
- 每个 tab 用固定 `key(i)` + `SaveableStateProvider(i)` 占位，旧页在过渡期间不重建（滚动/局部状态原地保留）。

`MainActivity`：

- `enableEdgeToEdge` 透明状态栏/导航栏。
- `LocalDensity` 覆盖：`fontScale = base.fontScale.coerceAtMost(1.25f)`。
- `AccentThemeStore.current` 作为主题强调色。
- `onResume/onPause` 调 `CaptureCenter.setAppForeground(...)`，让悬浮确认卡在应用前台时收起。
- 冷启动才 `AppUpdate.maybeCheck`；从捕获通知进入时不弹权限提醒、不检查更新。

## 6. 交互与跳转

- 底部 tab：点不同项 → `tab = index`；点当前项 → `reenterTick++`，页面自己滚到顶部（账单/统计）。
  两个页面各自记 `lastReenterTick`，只在 tick **增大**时回顶；从别的 tab 切回来不会复位已保留的滚动位置。
- FAB → `navController.navigate("quickAdd")`。
- 返回：子页 `EcoTopBar` 的返回按钮 → `popBackStack()`；系统返回键走默认 Navigation 行为。
- 通知路由：`MainActivity.consumeRoute` 更新 `navEvent`，`AccBookNav` 的 `LaunchedEffect` 负责 `navigate`。
- 冷启动权限弹窗：
  - 「去设置」→ 清空弹窗并 `navigate("settings/permissions")`。
  - 「以后再说」→ 清空，不导航。
- 更新弹窗：下载中不可关闭；「立即更新」先过安装未知应用授权；失败回弹窗可重试。

## 9. 坑与验收

**坑**

1. **不要**把 `MainScaffold` 的 tab 切换改回默认 `AnimatedContent` / `HorizontalPager`：两者都会让旧页在 z 序上参与命中测试，旧页 `pointerInput` 挡住新页点击。当前实现是“固定 key 占位 + 旧页仅作底图 + `blockPointerInput()`”，改的时候几个条件必须同时保留：每个 tab 只能有一份 `SaveableStateProvider`；旧页必须在**新页下层**（`zIndex = 0`）且消费 `PointerEventPass.Initial`。
2. 页面根节点不要自己再画背景；`EcoBackdrop` 只应存在一份，否则出现色带。
3. 底部栏高度变化时，必须同步 `ecoBottomContentPadding` / `ecoFabBottomOffset`，否则所有页面底部会被遮。
4. 字体上限只能改 `MainActivity` 一处；不要在页面里再压 `fontScale`。
5. 新增路由后，通知/快捷方式的 `when` 分支不会自动支持；需要就补。
6. `MainScaffold` 的 `SaveableStateProvider` 只保存 `rememberSaveable`；普通 `remember` 在切 tab 后丢失，若需要保留要改用 `rememberSaveable`。
7. 更新弹窗使用原生 `AlertDialog`（系统级），不要为了统一风格换成 `EcoDialog`，下载进度/系统安装流程依赖它。
8. **内容动画按设计每次进入重播**：`EcoCountUpMoney` / `EcoProgressBar` / 首页预算环 / 统计柱都在
   页面重新进入时从 0 播放，这是产品口径，不要改成“首帧即目标值”；页面层的闪白已由“旧页底图 + 交叉淡入”解决。

**验收**

- [ ] 四个 tab 切换无重叠、无残留点击拦截。
- [ ] 切换全程任何一帧都有页面内容，不出现纸面空白帧；内容动画（金额/环/柱/进度条）按设计每次进入重播。
- [ ] 再次点当前 tab，账单/统计回到顶部；从别的 tab 切回来保持原滚动位置。
- [ ] 首页/账单有 FAB，统计/个人没有。
- [ ] 子页返回不回到错误的 tab。
- [ ] 冷启动缺权限只弹一次；从通知进入不弹。
- [ ] 字体 1.25 下顶栏标题不裁、底部导航不挤。
- [ ] 深浅色下底栏/状态栏图标可读。
- [ ] 通知路由逐条验证：pending / refundLink / edit / quickAdd / import / overlay test。
