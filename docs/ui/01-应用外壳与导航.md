# 01 · 应用外壳与导航

这一页不是业务页面，而是所有页面共同的“舞台”：Activity、主题、路由、四 tab、底部栏、FAB、转场、全局弹窗。改业务页通常不需要动它；动它之前必须确认不影响 4 个 tab 和 21 条路由。

源码：

- `app/src/main/java/com/controleco/app/MainActivity.kt`
- `app/src/main/java/com/controleco/app/ui/AppNav.kt`
- `app/src/main/java/com/controleco/app/ui/eco/EcoScaffold.kt`（`EcoBottomNav` / `EcoFab` / `ecoBottomContentPadding` / `EcoToastHost`）
- `app/src/main/java/com/controleco/app/ui/common/PermissionReminderDialog.kt`

- `CaptureCenter.ROUTE_PENDING` → `pending`
- `ROUTE_REFUND_LINK` → `refundLink`
- `ROUTE_EDIT_PREFIX + id` → `edit/{id}`
- `quickAdd` → `quickAdd`
- `settings/developer` / `settings/permissions` → 直达
- `ROUTE_OVERLAY_TEST` → 直接 `CaptureCenter.showOverlayTest(...)`，不落库、不导航

**路由名是通知契约，不要改。**

## 3. 从上到下的外壳骨架

```
MainActivity
  AccBookTheme(AccentThemeStore.current)
    CompositionLocalProvider(LocalAnimationsEnabled provides (AnimationPrefs.enabled && !showSplash))
      Box(fillMaxSize)
        if (contentMounted)                 // 冷启动时等开屏画出第一帧再挂载
          AccBookNav(vm, navEvent, promptPermissions)
            Box(fillMaxSize)
              EcoBackdrop()                 // 全局纸面
              NavHost(...)                  // 当前路由页面
              EcoToastHost(bottom = 112dp)  // 浮在最上
            PermissionReminderDialog(...)   // 与 NavHost 并列
            HelpIntroDialog(...)            // 首次使用引导，同样与 NavHost 并列
          UpdateAvailableDialog()           // 最外层，系统对话框
        if (showSplash) ColdStartSplash()   // 冷启动开屏，压在最上层

MainScaffold(tab)
  Box(fillMaxSize)
    Box(graphicsLayer: translationY = (1 - pageIn) * 10dp)   // 只做一层整体位移
      SaveableStateProvider(tab)
        TabPage(tab)                                          // 0 Home / 1 TransactionList / 2 Stats / 3 Profile
    EcoBottomNav(selected = tab, align BottomCenter)
    AnimatedVisibility(visible = tab == 0 || tab == 1)
      EcoFab(align BottomEnd, end=19, bottom=ecoFabBottomOffset())
```

关键点：

- 四个 tab 的内容**互斥**，同一时刻只渲染 `tab` 这一页；切页时旧页立即移除，新页**整体上移 10dp 就位**（220ms）。
- **只动一层 `translationY`**：`graphicsLayer` 在绘制阶段改变换矩阵，不重组、不重新测量整页，也不产生全屏离屏缓冲。
  这是之前实测帧率最高的方案——不要改回“两页同时平移/整页 alpha 交叉淡化”：那会每帧重绘两整页，帧率明显下降。
- `pageIn = remember(tab) { Animatable(if (hasSwitched) 0f else 1f) }`：每次换 tab 新建一个从 0 开始的进度；
  `hasSwitched` 保证启动首帧直接是 1，不播开场位移。
- 内容动画（金额滚数、环、柱状图等）照常在页面组合时播放，与这 220ms 位移并行；单页 + 无离屏缓冲，实测流畅。
- 页面状态靠 `SaveableStateProvider(tab)` + `rememberSaveable` 保留：切走再回来仍在。
- FAB 跟随 `tab`，切换时淡出+缩小，不会突然消失。
- 底部栏永远 overlay，不参与内容测量。

### 3.1 冷启动开屏（提前预热）

```
ColdStartSplash(onFinished)
  Box(fillMaxSize, background=eco.paper, graphicsLayer alpha = bgAlpha)   // 纸面起始就不透明
    Image(ic_launcher_art, 104dp, 圆角 26dp, alpha/scale 动画)
```

- 节奏：logo 淡入 240ms（同时 0.90→1 轻微放大）→ 停留 300ms → logo 与纸面一起淡出 240ms。
- **预热**：冷启动首帧只画开屏（`contentMounted=false`），`withFrameNanos{}` 之后才把 `AccBookNav` 挂上，
  于是真实内容在开屏**后面**完成组合/布局/首绘——用户第一眼看到的是开屏，而不是空屏后再卡一下。
- **开屏期间压住内容动画**：`LocalAnimationsEnabled provides (AnimationPrefs.enabled && !showSplash)`。
  内容先定格在终值（这也正是要预热的那一帧画面），开屏淡出瞬间开关翻转，金额/环/柱状图再统一重播，入场不会被开屏吃掉。
- 只在冷启动播（`savedInstanceState == null`），旋转/重建不重播；`showSplash` 用 `rememberSaveable` 兜底。

### 3.2 「显示动画」总开关

- 设置页（`系统` 分组第一行）单行开关「显示动画」，无副标，默认开启；存 `eco_ui` / `show_animations`（`AnimationPrefs`）。
- 根节点用 `CompositionLocalProvider(LocalAnimationsEnabled …)` 下发，组件读 `LocalAnimationsEnabled.current`。
- 关闭后**直接定格终值**（不播逐帧动画）：金额不滚数、圆环/进度条直接到位、柱状图不升起、
  个人页卡片不弹入、首页卡面不翻转（等价 `rememberReducedMotion()`）、`EcoBackdrop` 几何层直接显形、切 tab 不做 10dp 上移、冷启动不播开屏。
- 开关切换即时生效：相关 `LaunchedEffect` 都以 `animationsEnabled` 为 key。

## 5. 状态与数据流

`AccBookNav` 持有：

- `permissionMissing: List<PermissionKind>`：冷启动时 `CapturePermissions.claimLaunchPrompt()` 返回的缺失权限；展示后清空。
- `helpPrompt: Boolean`（`rememberSaveable`）：是否弹「要看使用方法吗」；由 `HelpOnboarding.shouldPrompt` 在冷启动判一次，弹过即写 `help_prompted`。
- `vm: LedgerViewModel`：Activity 级 `viewModel()`，所有页面共享同一实例。
- `navEvent: Pair<Long, String?>`：Activity 自增序号 + route，保证同一路由重复点击也能触发。

`MainScaffold` 持有：

- `tab: Int`（`rememberSaveable`，0–3）：底栏高亮 + 当前渲染页，点击即变。
- `hasSwitched: Boolean`：是否发生过切换；首帧为 false，此时 `pageIn` 直接取 1，不播开场位移。
- `pageIn: Animatable`：`remember(tab)`，每次换页从 0→1，驱动 `translationY = (1 - pageIn) * 10dp`。
- `reenterTick: Int`（再次点当前 tab 时 +1），传给账单/统计用于回顶。
- `SaveableStateProvider(tab)`：按 tab 保存 `rememberSaveable`/滚动状态，切走再回来仍在。

`MainActivity`：

- `enableEdgeToEdge` 透明状态栏/导航栏。
- `LocalDensity` 覆盖：`fontScale = base.fontScale.coerceAtMost(1.25f)`。
- `AccentThemeStore.current` 作为主题强调色。
- `onResume/onPause` 调 `CaptureCenter.setAppForeground(...)`，让悬浮确认卡在应用前台时收起。
- 冷启动才 `AppUpdate.maybeCheck`；从捕获通知进入时不弹权限提醒、不检查更新。

## 6. 交互与跳转

- 底部 tab：点不同项 → `tab = index`；点当前项 → `reenterTick++`，页面自己滚到顶部（账单/统计）。
  两个页面各自记 `lastReenterTick`，只在 tick **增大**时回顶；从别的 tab 切回来不会复位已保留的滚动位置。
- FAB → `navController.navigate("quickAdd")`。
- 返回：子页 `EcoTopBar` 的返回按钮 → `popBackStack()`；系统返回键走默认 Navigation 行为。
- 通知路由：`MainActivity.consumeRoute` 更新 `navEvent`，`AccBookNav` 的 `LaunchedEffect` 负责 `navigate`。
- 冷启动权限弹窗：
  - 「去设置」→ 清空弹窗并 `navigate("settings/permissions")`。
  - 「以后再说」→ 清空，不导航。
- 首次使用帮助引导（`HelpIntroDialog`）：
  - 触发条件：冷启动（`promptPermissions`）、不是从通知进入（`navEvent.second == null`）、
    **没有缺失权限**（让权限提醒优先）、`HelpOnboarding.shouldPrompt` 为 true（没看过也没问过）。
  - 「查看帮助」→ `navigate("settings/help")`，进入即写 `help_viewed`。
  - 「暂不查看」/点遮罩 → 关闭；已写 `help_prompted`，之后不再自动弹。
- 更新弹窗：下载中不可关闭；「立即更新」先过安装未知应用授权；失败回弹窗可重试。

## 9. 坑与验收

**坑**

1. **不要**把 `MainScaffold` 的 tab 切换改回默认 `AnimatedContent` / `HorizontalPager`，也不要改成“两页同时平移”或“整页 alpha 交叉淡化”：当前是单页 `translationY` 位移，实测帧率最高。必须保留：同一时刻只组合 `tab` 这一页；位移在 `graphicsLayer` 里读；页面状态交给 `SaveableStateProvider(tab)`。
2. 页面根节点不要自己再画背景；`EcoBackdrop` 只应存在一份，否则出现色带。
3. 底部栏高度变化时，必须同步 `ecoBottomContentPadding` / `ecoFabBottomOffset`，否则所有页面底部会被遮。
4. 字体上限只能改 `MainActivity` 一处；不要在页面里再压 `fontScale`。
5. 新增路由后，通知/快捷方式的 `when` 分支不会自动支持；需要就补。
6. `MainScaffold` 的 `SaveableStateProvider` 只保存 `rememberSaveable`；普通 `remember` 在切 tab 后丢失，若需要保留要改用 `rememberSaveable`。
7. 更新弹窗使用原生 `AlertDialog`（系统级），不要为了统一风格换成 `EcoDialog`，下载进度/系统安装流程依赖它。
8. **内容动画按设计每次进入重播**：`EcoCountUpMoney` / `EcoProgressBar` / 首页预算环 / 统计柱都在
   页面重新进入时从 0 播放，这是产品口径，不要改成“首帧即目标值”；页面切换的观感由“淡出→换页→淡入”承担。
9. **滚数不要每帧重新量字号**：`EcoCountUpMoney` 把最终值作为 `fitText` 传给 `EcoAutoMoney`，
   测量结果按 `fitText` 缓存、数值变化时自动失效；逐帧变化的文本沿用该模式，不要直接拿动画中的 `text` 去量。
10. **帮助引导不要和权限提醒同时弹**：冷启动两条都满足时先弹权限提醒，帮助引导留到下一次启动
    （`helpPrompt` 的判断里带 `permissionMissing.isEmpty()`）。
11. **帮助引导只问一次**：`help_prompted` 在弹窗展示时就写入，不要改成「用户真的看了帮助才写」，
    否则「暂不查看」的用户每次启动都被问。

**验收**

- [ ] 四个 tab 切换无重叠、无残留点击拦截；切换是单页上移就位，滑动/切换过程不卡顿。
- [ ] 底栏未选中图标正常显示（胶囊 alpha 只作用于背景，不能连带图标）。
- [ ] 内容动画（金额/环/柱/进度条）按设计每次进入重播，且滚动/切换不掉帧。
- [ ] 再次点当前 tab，账单/统计回到顶部；从别的 tab 切回来保持原滚动位置。
- [ ] 首页/账单有 FAB，统计/个人没有。
- [ ] 子页返回不回到错误的 tab。
- [ ] 冷启动缺权限只弹一次；从通知进入不弹。
- [ ] 没看过帮助页时冷启动弹一次「要看使用方法吗」；看过或问过后不再弹；缺权限的那一轮不弹（下次启动才问）。
- [ ] 字体 1.25 下顶栏标题不裁、底部导航不挤。
- [ ] 深浅色下底栏/状态栏图标可读。
- [ ] 通知路由逐条验证：pending / refundLink / edit / quickAdd / import / overlay test。
