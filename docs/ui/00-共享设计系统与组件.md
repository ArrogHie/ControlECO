# 00 · 共享设计系统与组件

本文件是页面文档的共同底座。改任何页面之前先确认：**颜色、字号、间距、组件行为都从这里来**，不要在各页另造一套。

- `app/src/main/java/com/controleco/app/ui/eco/EcoFoundation.kt`

## 1. 画布与栅格

- 设计基准：**390dp 宽**（真机 1280×2772 / density 520 ≈ 393.8dp）。
- 主页面内容左右 **22dp**；设置页统一 `SettingsPagePadding = 22.dp`；设置页底部 `SettingsPageBottom = 32.dp`。
- 页面是 edge-to-edge：状态栏由 `EcoTopBar` 的 `statusBarsPadding()` 处理；底部导航/手势条由 `ecoBottomContentPadding()` / `navigationBarsPadding()` 处理。
- 页面根节点通常是 `Column(Modifier.fillMaxSize())`，不要在外面套 `Scaffold`。
- 主页面顶栏高：无返回 **72dp**，子页 **64dp**；都已含 `statusBarsPadding()`。
- 底部导航：内容行 **78dp** + 系统导航栏；页面底部留白 = `78.dp + navBottom + extra`（`ecoBottomContentPadding`）。
- FAB 距底 = `78.dp + navBottom + 14.dp`（`ecoFabBottomOffset()`）；FAB 外框 62dp，本体 50dp。
- 分区之间的纵向节奏：章节头 `padding(top=22, bottom=9)`；卡片之间 8–12dp；页面收尾 26–32dp。

### 字体缩放

`MainActivity` 用 `LocalDensity` 把系统 `fontScale` 压到 **≤ 1.25**：

```kotlin
val base = LocalDensity.current
CompositionLocalProvider(
    LocalDensity provides Density(base.density, base.fontScale.coerceAtMost(1.25f)),
)
```

因此：

- 所有页面必须在 **fontScale 1.25** 下验收。
- 固定高度卡片（个人页 hero、双列、分类卡；账单行；设置行）要预留 1–2 行文字的余量。
- 金额一律用 `EcoAutoMoney` / `EcoCountUpMoney` / `FittedAmountText` 这类自适应组件，不要直接 `Text(fontSize=48.sp)`。

## 2. 颜色 token

入口：

```kotlin
val c = MaterialTheme.eco          // EcoColors，深浅色 + 强调色预设
MaterialTheme.accBook              // 旧语义色，仅未迁移组件/分类色板
```

`EcoColors` 字段（全部随深浅色变化）：

| 用途 | token |
| --- | --- |
| 页面底色 | `paper` / `paperDeep` |
| 卡片/陶瓷面 | `surface` / `surface2` / `surface3` / `surfaceInset` |
| 主文字 | `ink` / `ink2` |
| 次文字 | `muted` |
| 弱文字/说明 | `quiet` |
| 分隔线 | `rule` / `ruleStrong` |
| 轨道/占位 | `track` |
| 主强调（随主题） | `blue` / `blueDeep` / `blue2` / `blueHi` / `blueSoft` / `blueWash` |
| **次强调（随主题）** | `second` / `secondDeep` / `second2` / `secondHi` / `secondSoft` / `secondWash` |
| 实心块上的前景 | `onAccent`（压 `blueDeep`）/ `onSecond`（压 `secondDeep`）/ `onAccentGrad`（压按钮渐变） |
| 正向（收入/安全） | `jade` / `jadeHi` / `jadeSoft` |
| 警示（预算偏紧） | `amber` / `amberHi` / `amberSoft` |
| 危险（超支/删除） | `clay` / `clayHi` / `claySoft` |
| 辅助紫 | `violet` / `violetSoft` |
| 深色 hero 渐变（左上亮 → 右下深） | `heroA` / `heroB` / `heroC`（派生：`heroGradient`） |
| 主操作渐变（按钮/FAB） | `accentGradA` / `accentGradB` / `accentGradC`（派生：`accentGradient`） |
| hero 前景 | `onHero` / `onHeroMuted` / `onHeroChip` / `onHeroBorder` / `heroProgress` / `heroPlate` |
| 是否深色 | `isDark` |

选色规则：

- 主操作、链接、选中：`blue` / `blueDeep`；浅底 `blueSoft`。
- 装饰性色块（卡片底、按钮、图标、背景点缀）想要和主色区分时，用 `second*`；
  它是主色旋转出来的第二个色相，同样随主题变。
- 收入、成功、已连接：`jade`；浅底 `jadeSoft`。
- 警告、待补、预算接近上限：`amber`；浅底 `amberSoft`。
- 超支、删除、错误、退款异常：`clay`；浅底 `claySoft`。
- 正文永远 `ink`，不要用纯黑 `Color.Black`。
- **禁止**在页面里新写 `Color(0xFF...)`；确需固定色（MIST/CLAY 封面风格、微信/支付宝品牌色、主题彩虹图标）必须就近注释原因。
- 压在实心色块上的文字/图标**不要写 `Color.White`**，用 `onAccent` / `onSecond` / `onAccentGrad` / `onHero*`：
  暖金、深色模式高亮档、白主题的按钮都是浅底，白字会糊。
- **例外：FAB 上的加号/图标固定纯白**（`EcoFab`、`EcoSquareFab`）。它是图形不是正文，
  3:1 即可；渐变提亮后 `onAccentGrad` 会自动翻成深墨色，白加号在这套「彩色渐变 + 白描边」里才是对的。
- **语义色只留给有语义的地方**，但有两处是**产品口径指定的固定色**（不随主题变）：
  设置卡固定暖金 `amber`、打赏钮固定陶红 `clay`。
  其余装饰卡片（分类卡、待确认清零态等）不要借语义色，要区分就用 `blue*` / `second*` 两个色相。

### 强调色预设

`EcoAccent`：`Tide`（潮汐，默认青蓝）、`Meadow`（松林玉绿）、`Iris`（鸢尾暮紫）、`Coral`（珊瑚陶红）、`Amber`（暖金琥珀）、`Sky`（晴海天青）、`White`（纯白，新增）。

- 入口：个人页主题卡（`ThemeSheet`）→ `AccentThemeStore.set`。
- 持久化在 `AccentThemeStore`，启动时 `AccBookTheme(accent = AccentThemeStore.current)`。
- 页面不要读取具体预设；只读 `MaterialTheme.eco`。

每套 `EcoAccent` 携带五组东西，**换主题时这五组一起变**：

| 字段 | 作用 |
| --- | --- |
| `light` / `dark` | 六档**主色**族（`Family`）：`blue` `deep` `mid` `hi` `soft` `wash` |
| `secondaryShift` | **次要色**的色相偏移（度）。主色族整体旋转即得 `second*`，明度/饱和度关系不变 |
| `heroA/B/C` | hero / 封面深色渐变（永远偏深，配白系前景） |
| `accentGradA/B/C` | 按钮 / FAB 主操作渐变（比 hero 亮） |
| `neutral` / `neutralDark` | 中性面色调：`TINTED`（近白+主题色）/ `WHITE`（纯白）/ `GRAPHITE`（石墨） |

### 主色与次要色

这是「换主题后每个页面都变」的第二条腿：

| 色相 | 用途 | 例 |
| --- | --- | --- |
| 主色 `blue*` / `accentGrad*` | 主操作（按钮、FAB、选中态、聚焦框）、主视觉 | 设置卡、底栏选中胶囊 |
| 次要色 `second*` | 装饰性但需要与主色区分的地方 | 分类卡、打赏钮、背景十字/圆点 |

各主题的次要色色相（实测）：潮汐 190°→320°、松林 163°→100°、鸢尾 256°→346°、
珊瑚 346°→296°、暖金 30°→90°、晴海 201°→115°、纯白（中性灰，旋转后仍是灰）。

**次要色不能撞语义色**：语义绿 ≈163°、警告金 ≈38°、危险红 ≈10°、辅助紫 ≈271°。
所以晴海的次要色从「松绿」改到了「草绿」（避开 163°）；`ThemeSecondColorTest` 会检查
`second` 与四个语义色的 ΔE 都 > 20。

### 主题色整体提亮

第一轮为了修对比度把 hero、按钮渐变、主色深档压得偏黑，整套主题发闷。现在分两套机制：

**1）按混合比例提亮**（`blue*` / `second*`，色相本身要对，亮度只需微调）：

| 常量 | 值 | 作用对象 |
| --- | --- | --- |
| `ACCENT_LIFT` | 0.12 | `blue` / `blue2` |
| `ACCENT_LIFT_DEEP` | 0.08 | `blueDeep`（实心块底，白字压着，要保守） |
| `ACCENT_LIFT_HI` | 0.05 | `blueHi`（本来就亮，避免糊白） |
| `ACCENT_LIFT_SECOND` | 0.06 | `second` / `second2`（装饰色，少提以免被冲淡） |

**2）按目标亮度归一化**（`hero*` / `accentGrad*`，见下）：用 `vividTone(color, target, satScale)`
在 HSV 里二分抬 V 把颜色推到目标相对亮度，**S 按系数缩放**（而不是向白混合）。
**7 套主题的明暗因此完全一致**，且彩色主题保住彩度。

| 常量 | 值 | 压在什么上面 |
| --- | --- | --- |
| `HERO_LUMA_A/B/C` | 0.108 / 0.140 / 0.172 | 白字（`onHero`），要求 ≥ 4.5:1 |
| `GRAD_LUMA_A/B/C` | 0.285 / 0.235 / 0.185 | 白图标 / 白字，要求 ≥ 3:1 |
| `HERO_SAT_SCALE` | 0.95 | 封面彩度系数，1.0 = 作者原色 |
| `GRAD_SAT_SCALE` | 0.98 | 主操作渐变，比封面再收敛一点 |
| `NEUTRAL_SAT_SCALE` | 0.15 | 纯白主题专用，把原始那点蓝味压成无彩色 |

**为什么不用「向白色混合」**：混白会同时抬高亮度、**冲淡彩度**，
深绿封面会变成灰青（`#4C7377`），观感「太灰」。
改成抬 V、按系数缩放 S，同亮度下还能保住色相。

**彩度系数别贪**：一度用 1.18（加饱和），结果「太鲜艳」。
1.0 是作者原色，< 1 收敛。现在封面取 **0.95**——比原色略淡，柔和耐看。

`heroC` 的上限是**硬顶**：白字要 4.5:1 → 底色亮度 ≤ 0.183；
而 `onHero` 带一点主题色相、不是纯白，实际只能到 0.172（再高掉到 4.41:1）。

**不动**纸面、卡片面、分隔线、文字，所以层次不会被冲淡。派生色（`onHero*`、
`heroProgress`、`heroPlate`、`accentBorder`）都读提亮后的值，对比关系自动跟着走；
hero 变浅后前景系数同步上调（`onHero` 0.90→0.97、`onHeroMuted` 0.68→0.82）。

实测（潮汐，相对亮度 / 彩度）：

| token | 压暗时 | 掺白版（灰） | 现在 |
| --- | --- | --- | --- |
| `heroC`（亮端） | 0.080 | — | 0.174 / `#228082` S=0.74 |
| `heroB`（中间） | 0.056 | `#4C7377` S=0.35 | 0.140 / `#1E737C` S=0.76 |
| `heroA`（深端） | 0.035 | — | 0.108 / `#18666F` S=0.78 |

封面色值：`#0B3A40/#104A50/#14595B` → `#228082/#1E737C/#18666F` 一族。
其余主题亮端：松林 `#2C8167`、鸢尾 `#7869AE`、珊瑚 `#AA5A77`、暖金 `#926C41`、晴海 `#2C7AA6`。

> 想再亮就只有一条路：把这几张卡从「深色封面 + 白字」换成「浅色面 + 深字」。
> 深色底 + 白字在 4.5:1 下亮度到 0.172 就是天花板了。

### 封面渐变：单一色相的明暗体积感

**不要做「主色 → 次要色」的双色相渐变**。试过，观感「太鲜艳、过渡太明显」：
潮汐会从青绿跳到紫、晴海从蓝跳到草绿，卡面像两种颜色拼的。已废弃。

现在只用**一个色相**，靠明暗做体积感：

| 色标位置 | token | 相对亮度 | 说明 |
| --- | --- | --- | --- |
| 0%（左上） | `heroC` | 0.172 | 最亮 |
| 50% | `heroB` | 0.140 | 中间 |
| 100%（右下） | `heroA` | 0.108 | 最深 |

**方向是「左上亮 → 右下深」**，顺序为 `heroC → heroB → heroA`。
这一点很关键：卡片本身已经有「顶边 1px 白高光 + 底边内侧压深」，
渐变必须与它同向，光感才成立；反过来（左上深、右下亮）会像背光。

`heroGradient` 已把这个顺序收口，`EcoHeroCard` 默认值和 `BalanceCard` 都读它，
**不要在调用点再手写 `listOf(heroA, heroB, heroC)`**（那是反的）。

明暗跨度控制在 **1.4–1.9 倍**（`heroC` / `heroA` 亮度比）：

- 低于 1.4 → 看成纯色（这正是上一版被说「近乎纯色」的原因）；
- 高于 1.9 → 过渡突兀，像打了两块色。

现在实测 1.58–1.63，落在中间。

各主题实测（亮端 → 中间 → 深端）：

| 主题 | 色标 | 彩度 |
| --- | --- | --- |
| 潮汐 | `#228082 → #1E737C → #18666F` | 0.74–0.78 |
| 松林 | `#2C8167 → #267563 → #236856` | 0.66–0.68 |
| 鸢尾 | `#7869AE → #6C609D → #5B558D` | 0.39–0.40 |
| 珊瑚 | `#AA5A77 → #985272 → #7C4E6A` | 0.37–0.47 |
| 暖金 | `#926C41 → #81633D → #70583D` | 0.46–0.55 |
| 晴海 | `#2C7AA6 → #286F9A → #236186` | 0.73–0.74 |
| 纯白 | `#727475 → #67686A → #5A5C5E` | 0.03（无彩色） |

### 背景：近白 + 一点主题色

`paper` / `surface` 不再是一组固定的青灰，而是**由强调色派生**：

| token | 着色比例 | 效果 |
| --- | --- | --- |
| `surface` | 1% | 几乎纯白（卡片面） |
| `paper` | 3% | 近白，只有一点点主题色相 |
| `paperDeep` | 7% | 凹陷/次级底 |
| `surface2` / `surface3` | 5% / 9% | 分层卡片 |
| `track` | 12% | 轨道 |
| `rule` / `ruleStrong` | 15% / 25% | 分隔线、描边 |

面积越大越白，只有线条和次级面才看得出色相。深色模式同理，底色按 10–17% 叠主题色，
不再是「所有主题都一片深青」。

### 白主题

`EcoAccent.White` 是唯一**不**给中性面着色的主题：

- 浅色：`paper`、`surface` 都是纯白 `#FFFFFF`，`paperDeep/surface2/surface3` 是中性浅灰（饱和度 < 0.05），
  强调色是墨黑（`#2F3134`），按钮走石墨渐变。目的是「大面积留白 + 深色主操作」的现代观感。
- 深色：石墨底（`#121212` 起），不是纯黑，也不是偏青的深蓝。
- 其余 6 套主题的纸面是「近白 + 各自的主题色」（3% 着色），所以换主题时底色也会微微变化。

### 换主题到底变了什么（口径）

| 会跟着变 | 不变 |
| --- | --- |
| 主按钮 / FAB / 方形 FAB 渐变 | 收入 `jade`、警告 `amber`、危险 `clay`、辅助 `violet` |
| 底栏选中胶囊、选中页指示点、chip 选中态 | 白主题下这些语义色同样不变 |
| 所有描边、聚焦框、进度条 | 分类图标的 8 色色板（但其中一个槽位来自主题） |
| hero / 结余卡「夜色」封面 / 设置页状态卡 | 薄雾、陶土两种封面风格 |
| 页面背景微光（右上主光 + 左下补光） | 微信/支付宝品牌色、主题彩虹图标 |
| **纸面/卡片/分隔线/轨道的色相**（近白 + 主题色） | 品牌色、MIST/CLAY 封面、相册图上的文字配色 |
| **装饰性色块**走 `second*`：分类卡、待确认清零态、背景十字/圆点 | 设置卡（固定暖金）、打赏钮（固定陶红） |

### 旧色板

`MaterialTheme.accBook.categoryPalette` 只用于分类图标/分类色轮/账户首字取色（`categoryColor(palette, name)`）。
色板第 5 槽（深色第 1 槽）由当前强调色生成（`accentPaletteSlot`，取离其余 7 色最远的一档），
所以**换主题时这个槽位会变**，其余 7 色固定。两套色板任意两色 ΔE ≥ 30（`AccentThemeTest` 守着）。

新 UI 不要再用 `AccBookColors.income/warning/...`，统一用 `eco.jade/amber/clay`。
`accBook.primaryStrong` 也已改由强调色驱动（`PeriodControls` / `Components` 已迁到 `eco.blue*`）。

用法：

- 直接 `style = EcoType.RowTitle`；需要局部变化用 `.copy(fontSize = ..., fontWeight = ...)`，不要另建 TextStyle。
- 中文标题不要加负字距；金额类 token 已带 `-0.05 ~ -0.078` 字距和 `tnum`（等宽数字）。
- 页面里出现的新字号先问：能不能用现有 token？不能才在页面文件内定义私有 `TextStyle` 并注释。

## 5. 版式语法

### 主页面

```
Column(fillMaxSize)
  EcoTopBar(micro, title, low?, action?)
  Box/weight(1f) 内容（可滚动）
  ...底部 Spacer(ecoBottomContentPadding(...))
```

### 子页

```
Column(fillMaxSize)
  EcoTopBar(micro, title, onBack)
  Column(weight(1f).verticalScroll(...).padding(horizontal=22))
    页首说明（可选）
    卡片/章节
    页尾说明
```

### 列表页

- 短列表：`Column + verticalScroll`。
- 长列表/需要吸顶：`LazyColumn`，并且它必须是整页唯一滚动容器。
- 不要在 `verticalScroll` 的 Column 里放 `LazyColumn`（无限高约束会崩）；设置页用 `SettingsLazyPage`。

### 卡片

- 普通卡：`EcoPane { Column { ... } }`，行间 `EcoRowDivider()`。
- 强调卡：`EcoHeroCard`，固定深色渐变 + 白系前景。
- 统计/账单的结余封面：`BalanceCard`（共享组件，见 03/04）。

### Sheet / Dialog

- 表单、选择、确认明细：`EcoSheet`（标题 + 可选副标 + 内容）。
- 二次确认/危险操作：`EcoConfirm`。
- 自定义内容弹窗：`EcoDialog`。
- 所有 sheet 内容底部已有 26dp padding，不要再叠加导航栏 padding。

## 6. 动效约定

| 场景 | 规格 |
| --- | --- |
| 主页面切换 tab | 单页整体上移 10dp / 220ms：`graphicsLayer { translationY = (1 - pageIn) * 10dp }`，只动一层、无离屏缓冲（帧率优先）；**不要**改成两页平移或整页交叉淡化，每帧重绘两整页会明显掉帧 |
| 路由 push | **串行**：旧页 150ms 淡出 → 新页 260ms 淡入 + 下移 0.95%；pop：旧页 140ms 淡出 + 横向 1/32 → 新页 240ms 淡入。不要并行淡化：两页都有透明区域，中途 alpha 会互相透出（“上一页还在”） |
| 卡片入场 | `EcoArrival`：0.56s，三段 tween 364+106+90ms，每段 `cubic-bezier(.17,.8,.18,1)`，关键帧 0/65/84/100%；个人页 `randomDelay=true` 随机顺序 |
| 金额/图表/进度 | `EcoCountUpMoney` 940ms、`EcoProgressBar` 900ms、统计柱 820ms、首页环 1.1s/1.3s；**每次进入页面重播**（产品口径），与页面 220ms 上移叠加 |
| hero 装饰环 | 3.5s 呼吸；不要改成大面积 radial gradient（真机 Skia 会出现黑块） |
| FAB | 只有外圈呼吸（scale .95→1.07，alpha .20→.50），本体不动 |
| 呼吸/闪烁 | 光标 560ms；状态点 1.2s；解析环 1.2s |
| 减弱动效 | `LocalAnimationsEnabled`（设置里「显示动画」，默认 true）为 false 时全部入场动画直接定格终值；首页翻转另读 `rememberReducedMotion()`；其它无限动画保持低幅度 |
| 总开关 | `AnimationPrefs`（`eco_ui` / `show_animations`）→ `MainActivity` 用 `CompositionLocalProvider(LocalAnimationsEnabled …)` 下发；新增动画组件都要读它，关闭时 `snapTo(终值)`、并把 `animationsEnabled` 作为 `LaunchedEffect` key 以便即时生效 |

动画只做“进入/状态变化”，不要给每个点击都加转场；列表滚动不要绑动画。

## 7. 文案规则

- 标题 2–4 字；按钮 2–4 字；英文 micro 全大写。
- 状态词固定：`待确认`、`待补`、`红包`、`已退款`、`退款`、`不计预算`、`AA n`、`已连接`、`未开启`、`已就绪`、`待设置`。
- 删除确认只说明**这次操作的实际后果**（例如分类删除后流水归入「其他」）；不要预置“有流水就删不掉”这类尚未发生的规则。
- **任何文字前都不加 `·`**：不写「· 12 天」「· 待设置」，也不用 `·` 作字段分隔（`A · B`）；需要分隔用空格、`/` 或中文标点。
- **非必要说明不出现**：页面不预置规则、边界、能力限制的解释；只有用户触发时才用一次性提示/错误告知（分类重名、删「其他」、预算超限等）。
- 权限/保活/导入教程是功能组成，不要为了“简洁”删步骤；只压缩重复解释。
- 金额展示：
  - 账单行支出不带负号、收入带 `+`（`Money.formatSignedCurrency`，支出传负值）。
  - 余额/资产用 `Money.formatYuanGroupedFixed`。
  - 百分比整数化（`roundToInt`），不要显示多位小数。
- 空态必须说明“下一步做什么”，不要只写“暂无数据”。

## 9. 坑与验收

**坑**

1. 在 `verticalScroll` 里嵌 `LazyColumn` → 无限高约束崩溃；用 `SettingsLazyPage` 或整页单 `LazyColumn`。
2. `EcoSheet` 默认 `scrollable=true`，滚轮/地图类内容会被抢手势；传 `false`。
3. 底部栏是 overlay：内容底部没留 `ecoBottomContentPadding()` 会被遮住最后一屏。
4. 固定高度卡在 fontScale 1.25 下容易裁字；新增时用 `heightIn(min=...)` 或留 2 行余量。
5. 深色 hero 上的文字不要用 `eco.ink`（深色模式下会变白，但浅色主题下 hero 仍是深色，必须用固定 `HERO_*`）。
6. 不要给页面根节点加 `background`；`EcoBackdrop` 已铺底，重复铺会出现色带。
7. 不要把 `AnimatedContent` 用在四 tab 切换（旧页 pointerInput 会残留挡住新页）。
8. 分类色取色必须用 `categoryColor`，不要按数组下标轮询，否则新增分类会让旧分类换色。

**验收清单**

- [ ] fontScale 1.25 下无裁字、无横向溢出。
- [ ] 浅色 + 深色都检查；hero 前景色随主题变但始终可读。
- [ ] **7 套主题逐个切一遍**：主按钮、FAB、底栏选中胶囊、描边、hero、背景微光都跟着变；
      只有收入/警告/危险（绿/金/陶红）保持不变。
- [ ] **白主题**：页面与大卡片是白的（不是米白/青白），正文足够黑，看不出任何青绿残留。
- [ ] 内容滚动到底不被底部栏/FAB 遮挡。
- [ ] 返回键/返回按钮回到正确页面；再次点当前 tab 能回顶。
- [ ] 空态、加载态、错误态都有文案。
- [ ] 危险操作有 `EcoConfirm` 且 `danger=true`。
- [ ] 没有新增硬编码颜色/字号（MIST/CLAY 封面、品牌色、彩虹图标除外，且已注释）。
- [ ] `:app:assembleDebug` 与 `:app:testDebugUnitTest` 通过。
