# 00 · 共享设计系统与组件

本文件是页面文档的共同底座。改任何页面之前先确认：**颜色、字号、间距、组件行为都从这里来**，不要在各页另造一套。

源码：

- `app/src/main/java/com/controleco/app/ui/theme/Theme.kt`（token、`EcoType`、`AccBookTheme`）
- `app/src/main/java/com/controleco/app/ui/eco/EcoFoundation.kt`
- `app/src/main/java/com/controleco/app/ui/eco/EcoControls.kt`
- `app/src/main/java/com/controleco/app/ui/eco/EcoScaffold.kt`
- `app/src/main/java/com/controleco/app/ui/common/SettingsKit.kt`（设置类页面专用外壳）

## 1. 画布与栅格

- 设计基准：**390dp 宽**（真机 1280×2772 / density 520 ≈ 393.8dp）。
- 主页面内容左右 **22dp**；设置页统一 `SettingsPagePadding = 22.dp`；设置页底部 `SettingsPageBottom = 32.dp`。
- 页面是 edge-to-edge：状态栏由 `EcoTopBar` 的 `statusBarsPadding()` 处理；底部导航/手势条由 `ecoBottomContentPadding()` / `navigationBarsPadding()` 处理。
- 页面根节点通常是 `Column(Modifier.fillMaxSize())`，不要在外面套 `Scaffold`。
- 主页面顶栏高：无返回 **72dp**，子页 **64dp**；都已含 `statusBarsPadding()`。
- 底部导航：内容行 **78dp** + 系统导航栏；页面底部留白 = `78.dp + navBottom + extra`（`ecoBottomContentPadding`）。
- FAB 距底 = `78.dp + navBottom + 14.dp`（`ecoFabBottomOffset()`）；FAB 外框 62dp，本体 50dp。
- 分区之间的纵向节奏：章节头 `padding(top=22, bottom=9)`；卡片之间 8–12dp；页面收尾 26–32dp。

### 字体缩放

`MainActivity` 用 `LocalDensity` 把系统 `fontScale` 压到 **≤ 1.25**：

```kotlin
val base = LocalDensity.current
CompositionLocalProvider(
    LocalDensity provides Density(base.density, base.fontScale.coerceAtMost(1.25f)),
)
```

因此：

- 所有页面必须在 **fontScale 1.25** 下验收。
- 固定高度卡片（个人页 hero、双列、分类卡；账单行；设置行）要预留 1–2 行文字的余量。
- 金额一律用 `EcoAutoMoney` / `EcoCountUpMoney` / `FittedAmountText` 这类自适应组件，不要直接 `Text(fontSize=48.sp)`。

## 2. 颜色 token

入口：

```kotlin
val c = MaterialTheme.eco          // EcoColors，深浅色 + 强调色预设
MaterialTheme.accBook              // 旧语义色，仅未迁移组件/分类色板
```

`EcoColors` 字段（全部随深浅色变化）：

| 用途 | token |
| --- | --- |
| 页面底色 | `paper` / `paperDeep` |
| 卡片/陶瓷面 | `surface` / `surface2` / `surface3` / `surfaceInset` |
| 主文字 | `ink` / `ink2` |
| 次文字 | `muted` |
| 弱文字/说明 | `quiet` |
| 分隔线 | `rule` / `ruleStrong` |
| 轨道/占位 | `track` |
| 主强调（蓝/青） | `blue` / `blueDeep` / `blue2` / `blueHi` / `blueSoft` / `blueWash` |
| 正向（收入/安全） | `jade` / `jadeHi` / `jadeSoft` |
| 警示（预算偏紧） | `amber` / `amberHi` / `amberSoft` |
| 危险（超支/删除） | `clay` / `clayHi` / `claySoft` |
| 辅助紫 | `violet` / `violetSoft` |
| 深色 hero 渐变 | `heroA` / `heroB` / `heroC` |
| 是否深色 | `isDark` |

选色规则：

- 主操作、链接、选中：`blue` / `blueDeep`；浅底 `blueSoft`。
- 收入、成功、已连接：`jade`；浅底 `jadeSoft`。
- 警告、待补、预算接近上限：`amber`；浅底 `amberSoft`。
- 超支、删除、错误、退款异常：`clay`；浅底 `claySoft`。
- 正文永远 `ink`，不要用纯黑 `Color.Black`。深色 hero 上的文字用该页固定的 `HERO_*` 常量（hero 永远深色，不随主题变）。
- **禁止**在页面里新写 `Color(0xFF...)`；确需固定色（hero 前景、FAB 渐变、分类色板）必须集中在文件顶部常量并注释原因。

### 强调色预设

`EcoAccent`：`Tide`（潮汐，默认青蓝）、`Meadow`（松林玉绿）、`Iris`（鸢尾暮紫）、`Coral`（珊瑚陶红）、`Amber`（暖金琥珀）、`Sky`（晴海天青）。

- 入口：个人页主题卡（`ThemeSheet`）→ `AccentThemeStore.set`。
- 持久化在 `AccentThemeStore`，启动时 `AccBookTheme(accent = AccentThemeStore.current)`。
- 页面不要读取具体预设；只读 `MaterialTheme.eco`。`heroA/B/C`、`blue*` 会自动跟随。

### 旧色板

`MaterialTheme.accBook.categoryPalette` 只用于分类图标/分类色轮/账户首字取色（`categoryColor(palette, name)`）。新 UI 不要再用 `AccBookColors.income/warning/...`，统一用 `eco.jade/amber/clay`。

### 4.5 周期控件（`PeriodControls.kt` / `WheelPicker.kt`）

- `periodLabel(...)`、`periodBalanceLabel(...)`、`periodScopeLabel(...)`：周期文案统一从这里取。
- `SegmentedSwitch` / `SlidingSwitch` / `PeriodSwitch`：月/年切换。
- `PeriodStepper`：‹ 周期 ›。
- `PeriodPickerSheet`：周期选择。
- `WheelPicker` / `WheelTrigger`：月起始日滚轮。
- **注意**：滚轮放在 `EcoSheet` 里必须 `scrollable = false`，否则 sheet 的垂直滚动会抢手势。

### 4.6 分类图标

- `CategoryLogo`（`common/CategoryLogo.kt`）：统一渲染 emoji / 相册图片 / 内置 glyph。
- `EcoCategoryTile` 是它的外框；颜色由 `categoryColor(palette, categoryName)` 稳定取色，分类自定义颜色优先。
- **`bare = true`（去掉底色与描边）** 用于：账单行、首页分类模式、分类管理（列表 + 编辑预览）。
  无底时图形按 `size` 满格绘制，视觉重量靠尺寸而非色块。
- **保留带底色 tile** 的场合：快速记账分类选择条、退款候选行、个人页分类卡、悬浮确认卡。
  这些是「可选中的按钮」或需要边界指示，去掉底会失去可点区域的视觉暗示。
- `EcoIconTile` 同理：设置页所有行图标（`SettingsRow`）与权限页总览卡用 `bare = true`；
  保活 hero、导入阶段图标、权限提醒弹窗保留底色。

## 5. 版式语法

### 主页面

```
Column(fillMaxSize)
  EcoTopBar(micro, title, low?, action?)
  Box/weight(1f) 内容（可滚动）
  ...底部 Spacer(ecoBottomContentPadding(...))
```

### 子页

```
Column(fillMaxSize)
  EcoTopBar(micro, title, onBack)
  Column(weight(1f).verticalScroll(...).padding(horizontal=22))
    页首说明（可选）
    卡片/章节
    页尾说明
```

### 列表页

- 短列表：`Column + verticalScroll`。
- 长列表/需要吸顶：`LazyColumn`，并且它必须是整页唯一滚动容器。
- 不要在 `verticalScroll` 的 Column 里放 `LazyColumn`（无限高约束会崩）；设置页用 `SettingsLazyPage`。

### 卡片

- 普通卡：`EcoPane { Column { ... } }`，行间 `EcoRowDivider()`。
- 强调卡：`EcoHeroCard`，固定深色渐变 + 白系前景。
- 统计/账单的结余封面：`BalanceCard`（共享组件，见 03/04）。

### Sheet / Dialog

- 表单、选择、确认明细：`EcoSheet`（标题 + 可选副标 + 内容）。
- 二次确认/危险操作：`EcoConfirm`。
- 自定义内容弹窗：`EcoDialog`。
- 所有 sheet 内容底部已有 26dp padding，不要再叠加导航栏 padding。

## 6. 动效约定

| 场景 | 规格 |
| --- | --- |
| 主页面切换 tab | 单页整体上移 10dp / 220ms：`graphicsLayer { translationY = (1 - pageIn) * 10dp }`，只动一层、无离屏缓冲（帧率优先）；**不要**改成两页平移或整页交叉淡化，每帧重绘两整页会明显掉帧 |
| 路由 push | fadeIn 300ms + 下移 0.95%；exit 延迟 170ms 再 180ms 淡出；pop：fade 280ms + 横向 1/32 |
| 卡片入场 | `EcoArrival`：0.56s，三段 tween 364+106+90ms，每段 `cubic-bezier(.17,.8,.18,1)`，关键帧 0/65/84/100%；个人页 `randomDelay=true` 随机顺序 |
| 金额/图表/进度 | `EcoCountUpMoney` 940ms、`EcoProgressBar` 900ms、统计柱 820ms、首页环 1.1s/1.3s；**每次进入页面重播**（产品口径），与页面 220ms 上移叠加 |
| hero 装饰环 | 3.5s 呼吸；不要改成大面积 radial gradient（真机 Skia 会出现黑块） |
| FAB | 只有外圈呼吸（scale .95→1.07，alpha .20→.50），本体不动 |
| 呼吸/闪烁 | 光标 560ms；状态点 1.2s；解析环 1.2s |
| 减弱动效 | `LocalAnimationsEnabled`（设置里「显示动画」，默认 true）为 false 时全部入场动画直接定格终值；首页翻转另读 `rememberReducedMotion()`；其它无限动画保持低幅度 |
| 总开关 | `AnimationPrefs`（`eco_ui` / `show_animations`）→ `MainActivity` 用 `CompositionLocalProvider(LocalAnimationsEnabled …)` 下发；新增动画组件都要读它，关闭时 `snapTo(终值)`、并把 `animationsEnabled` 作为 `LaunchedEffect` key 以便即时生效 |

动画只做“进入/状态变化”，不要给每个点击都加转场；列表滚动不要绑动画。

## 7. 文案规则

- 标题 2–4 字；按钮 2–4 字；英文 micro 全大写。
- 状态词固定：`待确认`、`待补`、`红包`、`已退款`、`退款`、`已连接`、`未开启`、`已就绪`、`待设置`。
- 删除确认只说明**这次操作的实际后果**（例如分类删除后流水归入「其他」）；不要预置“有流水就删不掉”这类尚未发生的规则。
- **任何文字前都不加 `·`**：不写「· 12 天」「· 待设置」，也不用 `·` 作字段分隔（`A · B`）；需要分隔用空格、`/` 或中文标点。
- **非必要说明不出现**：页面不预置规则、边界、能力限制的解释；只有用户触发时才用一次性提示/错误告知（分类重名、删「其他」、预算超限等）。
- 权限/保活/导入教程是功能组成，不要为了“简洁”删步骤；只压缩重复解释。
- 金额展示：
  - 账单行支出不带负号、收入带 `+`（`Money.formatSignedCurrency`，支出传负值）。
  - 余额/资产用 `Money.formatYuanGroupedFixed`。
  - 百分比整数化（`roundToInt`），不要显示多位小数。
- 空态必须说明“下一步做什么”，不要只写“暂无数据”。

## 8. 常见改法

| 想改 | 去哪里 |
| --- | --- |
| 全局主色/强调色 | `EcoAccent` 预设 + `Theme.kt` 的 `ecoColors` |
| 页面底色/卡片质感 | `EcoBackdrop`、`EcoPane`（不要逐页改） |
| 顶栏高度/标题字号 | `EcoTopBar` + `EcoType.TopTitle/SubTitle` |
| 底部栏高度/FAB 位置 | `EcoBottomNav`、`ecoBottomContentPadding`、`ecoFabBottomOffset` |
| 通用按钮/输入框 | `EcoControls.kt`；改前 grep 全项目调用点 |
| 设置页行距/分组 | `SettingsKit.kt`；所有设置子页共享 |
| 分类图标外观 | `EcoCategoryTile` + `CategoryLogo`；注意 `bare` 两种形态 |
| 字体缩放上限 | `MainActivity` 的 `coerceAtMost(1.25f)`，属于全局行为，改前确认所有页面 |

## 9. 坑与验收

**坑**

1. 在 `verticalScroll` 里嵌 `LazyColumn` → 无限高约束崩溃；用 `SettingsLazyPage` 或整页单 `LazyColumn`。
2. `EcoSheet` 默认 `scrollable=true`，滚轮/地图类内容会被抢手势；传 `false`。
3. 底部栏是 overlay：内容底部没留 `ecoBottomContentPadding()` 会被遮住最后一屏。
4. 固定高度卡在 fontScale 1.25 下容易裁字；新增时用 `heightIn(min=...)` 或留 2 行余量。
5. 深色 hero 上的文字不要用 `eco.ink`（深色模式下会变白，但浅色主题下 hero 仍是深色，必须用固定 `HERO_*`）。
6. 不要给页面根节点加 `background`；`EcoBackdrop` 已铺底，重复铺会出现色带。
7. 不要把 `AnimatedContent` 用在四 tab 切换（旧页 pointerInput 会残留挡住新页）。
8. 分类色取色必须用 `categoryColor`，不要按数组下标轮询，否则新增分类会让旧分类换色。

**验收清单**

- [ ] fontScale 1.25 下无裁字、无横向溢出。
- [ ] 浅色 + 深色都检查；hero 前景色不变。
- [ ] 内容滚动到底不被底部栏/FAB 遮挡。
- [ ] 返回键/返回按钮回到正确页面；再次点当前 tab 能回顶。
- [ ] 空态、加载态、错误态都有文案。
- [ ] 危险操作有 `EcoConfirm` 且 `danger=true`。
- [ ] 没有新增硬编码颜色/字号（除已注释的固定 hero 色）。
- [ ] `:app:assembleDebug` 与 `:app:testDebugUnitTest` 通过。
