# 06 · 快速记账

从首页/账单 FAB、快捷方式、磁贴、通知路由进入的单页表单。金额优先：大金额 → 三步引导 → 收支 → 分类 → 补充信息 → 数字键盘 → 记一笔。

源码：`app/src/main/java/com/controleco/app/ui/transactions/QuickAddScreen.kt`（约 605 行）
共享：`TxFormKit.kt`（`TxSelectField`、`TxDateField`、`TxCategoryChip`、`TxKeypad`）、`EcoField`、`EcoFilterStrip`、`EcoHairline`。

---

## 1. 路由与入口

- 路由：`quickAdd`。
- 进入：首页/账单 FAB、`CaptureCenter` 快捷方式/磁贴、通知路由 `quickAdd`。
- 离开：
  - 返回按钮 → `popBackStack()`
  - 保存成功 → `EcoToast("已记一笔")` 后 `onBack()`
- 无编辑模式；`txId` 固定传 `-1L`。

## 5. 状态与数据流

### 只读

`accounts`、`categories`（VM Flow）。

### 本地状态

| 状态 | 说明 |
| --- | --- |
| `amountText` | 键盘输入字符串 |
| `type` | `EXPENSE` / `INCOME` |
| `categoryId` / `accountId` | 当前选择 |
| `date` | 默认今天 |
| `counterparty` / `note` | 商户/备注 |
| `showMore` | 补充信息展开 |
| `categoryExpanded` | 分类 chips 展开 |
| `error` | 校验错误 |

### 默认值

`LaunchedEffect(accounts, categories, type)`：

- `accountId == null` → 第一个账户。
- 当前 `categoryId` 的类型 ≠ `type` → 该类型第一个分类。

### 校验与保存

- 键盘输入：
  - `.` 首次 → `0.`；已有小数点忽略。
  - 最多两位小数；整数最多 9 位。
  - 错误写入 `error`，在金额下方显示。
- `valid = 金额 > 0 && categoryId != null && accountId != null`。
- 保存时间：
  - `date == 今天` → `System.currentTimeMillis()`（含时分）。
  - 其它日期 → `date.atTime(LocalTime.now())`。
- `vm.saveTransaction(-1L, type, amount, categoryId, accountId, ts, note, counterparty)`。
- 成功 Toast + 返回；错误留在本页。

### 三步引导

`step`：无金额 0 → 有金额无分类 1 → 有金额有分类 2。`QuickGuide` 用 done/current 两种节点状态显示。

## 6. 交互与跳转

| 操作 | 结果 |
| --- | --- |
| 数字/`.`/退格/清空 | 改 `amountText` |
| 点收支 | 切类型，并自动校正分类到该类型首个 |
| 点分类条 | 展开/收起 chips |
| 点 chip | 选中分类（**不自动收起**） |
| 点「补充信息」 | 展开账户/日期/商户/备注 |
| 点账户/日期 | 下拉/日期选择（`TxSelectField` / `TxDateField`） |
| 点「记一笔」 | 校验 → 保存 → Toast → 返回 |
| 系统输入法弹出 | 隐藏数字键盘，表单让出高度；关闭输入法后数字键盘恢复 |

## 9. 坑与验收

**坑**

1. 键盘/主按钮必须固定在底部，不能跟着内容滚走；否则输入时够不到「记一笔」。
2. 系统输入法弹出时要**隐藏数字键盘**（`imeVisible`），否则两层键盘叠加把表单挤没。
3. 分类 chips 展开区最高 82dp 并自己滚动；不要让它无限长把键盘顶走。
4. 选完分类**不自动收起**，这是设计行为；不要“优化”成收起。
5. 金额最大 9 位整数 + 2 位小数；改限制必须同步改 `appendKey` 和 `FittedAmountText`。
6. 非今天日期保存时沿用**当前时刻**的时分，不是 00:00；改保存逻辑前确认口径。
7. 收支切换会自动把分类切到新类型的第一个；如果用户已选同类型分类则保留。
8. `AmountHero` 的径向光斑在部分屏幕/深色模式下可能出现可见的矩形边界；调整时优先降 alpha 或改半径，不要加大面积渐变。
9. 页面内容较短时，补充信息与键盘之间会留白；这是 `weight(1f)` 滚动区的自然结果，不是布局错误。

**验收**

- [ ] 0/1/2 三步引导随输入正确变化。
- [ ] 小数点、两位小数、9 位整数限制正确。
- [ ] 切收支后分类自动落在正确类型。
- [ ] 补充信息展开/收起，账户/日期/商户/备注都能编辑。
- [ ] 无账户/无分类时按钮禁用，错误提示正确。
- [ ] 数字键盘与系统输入法不重叠；主按钮始终可达。
- [ ] 保存后返回，首页/账单出现新记录且时间正确。
- [ ] fontScale 1.25 下大金额、分类条、按钮不裁。
