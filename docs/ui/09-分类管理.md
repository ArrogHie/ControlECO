# 09 · 分类管理

从个人页分类卡、首页分类模式铅笔、设置 → 账户入口进入。页面是“支出/收入两组分类 + 新增/编辑 sheet”；分类预算只作用于支出分类。

源码：`app/src/main/java/com/controleco/app/ui/accounts/CategoriesScreen.kt`（约 947 行）
共享：`CategoryIcon`、`ColorWheelDialog`、`PercentInput`、`EcoCategoryTile`、`EcoSegmented`、`EcoSquareFab`、`Glyph`/`GlyphIcon`。

---

## 1. 路由与入口

- 路由：`categories`。
- 进入：
  - 个人页分类卡
  - 首页分类模式右上管理铅笔
  - 设置 → 账户入口 → 分类管理
- 离开：返回。
- 新增：顶栏 `+` / 右下 `EcoSquareFab`。
- 编辑：点分类行。

## 5. 状态与数据流

### 只读

- `categories`
- `categoryBudgets`（分类 id → 金额）
- `categoryBudgetPercents`（分类 id → 万分比）
- `categoryBudgetMode`（全局显示/输入口径：金额 / 比例）
- `monthlyBudgetCents`

### 派生

- `expenseList` / `incomeList`。
- `allocatedCents = Σ 支出分类预算`。
- 页首：`支出分类 · 已分配 X / 月预算`；无月预算时 `· 未设月预算`。

### 本地

- `showEditor`、`editing`、`draftIcon`、`sheetError`、`freshImport`（本次刚导入的图片，取消时删除）。
- 图片选择器：系统相册 → `CategoryIcon.importImage` → `draftIcon = image(fileName)`。

### 编辑 sheet 内状态

`name`、`type`、`budgetText`、`percentCells`、`emojiText`、`localError`、`showColorWheel`、`showAllGlyphs`、`confirmDelete`。

派生：

- `glyphName` / `isGlyphBased` / `currentColor`。
- `previewGlyph` / `glyphTintColor`。
- `emojiInvalid`。
- `hasTotalBudget`、`allocatableCents`、`maxAllowedCents`（保留原值可保存）。
- `allocatableBp`、`maxAllowedBp`。
- `typedBp`、`typedCents`。

### 预算口径

- 全局 `budgetMode` 只改“显示/输入方式”，不改已有数值。
- sheet 内切换：
  - 切到比例：金额输入为空时，把金额折算成 bp 填入 percentCells。
  - 切到金额：比例为 0 时，把 bp 折算成金额填入。
  - 保留本次输入，不丢。

### 保存

`onSave(id, name, type, budgetCents, percentBp, icon)`：

- 名称空 → `请输入名称`。
- 金额/比例超可分配 → 错误（输入框 `isError`，文案在下方）。
- 成功：关 sheet；若删除过刚导入图片，调用 `discardFreshImport()`。
- VM 失败：`sheetError` 显示。

### 删除

- 仅编辑已有分类。
- `EcoConfirm(danger=true)`；确认后 `vm.deleteCategory(id)`。
- 成功：`discardFreshImport()`、关 sheet；失败 `sheetError`。
- 分类下有流水时后端拒绝，sheet 显示错误。

## 7. 文案

- 顶栏：`CATEGORIES` / `分类管理`；`新增分类`。
- 页首：`分类预算只作用于支出分类；在「金额 / 比例」之间切换不会改变已有数值，只改变显示与输入方式。`
- 分配：`支出分类 · 已分配 X / Y` / `· 未设月预算`。
- 分组：`01 支出分类`、`02 收入分类`、`{n} ITEMS`。
- 空态：`暂无支出分类` / `点右下角 + 新建一个分类，预算与图标都能在编辑卡里改`；`暂无收入分类` / `新增分类时把类型切到「收入」即可`。
- 行：`未设预算`、`收入`。
- 页尾：`删除分类不会删除已入账流水；分类下已有流水时无法删除。分类预算只影响首页与统计的预算读数。`
- 编辑 sheet：`新增分类` / `编辑分类`、`名称`、`例如：餐饮`、`类型`、`支出`/`收入`、`图标`、`按名称取形`、`更多图形（N）`/`收起图形`、`从相册选图`、`恢复默认`、`图形颜色`、`默认`、`Emoji 图标`、`在此输入 emoji 作为图标`、`分类月预算`、`金额`/`比例`、`每月金额`、`0.00`、`还可分配 X`、`未设置月总预算时不限制分类预算`、`保存`、`删除分类`。
- 删除确认：`删除分类` / `删除后不可恢复。分类下若已有流水，需要先处理这些账单才能删除。`

## 9. 坑与验收

**坑**

1. **金额/比例切换不改已有数值**，只改显示与输入；切换时会做一次折算填充，但不要覆盖用户已输入的值。
2. `maxAllowedCents/Bp` 取“可分配”与“本分类原值”的较大者：历史超标数据必须还能原样保存/下调。
3. 比例输入是“cell”制（`bpToCells` / `cellsToBp`），不要直接当百分比浮点算。
4. 本次刚导入的图片在取消/删除时要清理（`freshImport`），否则留孤儿文件。
5. 分类预算只对支出分类显示；收入分类不显示预算区块。
6. 删除分类不删流水；有流水时后端拒绝，错误显示在 sheet。
7. 分类图标**不带底色/描边**（`bare = true`，31dp 列表 / 44dp 编辑预览）；退款候选行等选择器才用带底色的 tile，不要混用。
8. 收入分类行的预算位置显示 `收入`，不是金额。
9. 自定义颜色与“默认按名称取色”是两种状态：`currentColor == null` 才是默认。

**验收**

- [ ] 支出/收入分组、数量、空态正确。
- [ ] 页首已分配金额 = 各支出分类预算之和。
- [ ] 金额/比例切换不丢数值，页首与行显示同步。
- [ ] 图标形状/颜色/emoji/相册图四种都能设置并预览。
- [ ] 超可分配预算有错误提示且不能保存。
- [ ] 删除分类二次确认；有流水时被拒绝并提示。
- [ ] 取消编辑不留下刚导入的图片文件。
- [ ] 1.25 字体下分类行、预算输入、图标宫格不裁。
