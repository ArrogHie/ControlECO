# 13 · 捕获日志

开发者功能 → 捕获日志。展示通知监听/无障碍/短信三条通道最近捕获到的原始记录，可按通道筛选，点行展开快照并复制原文。

源码：`app/src/main/java/com/controleco/app/ui/debug/CaptureLogScreen.kt`（约 538 行）

---

## 1. 路由与入口

- 路由：`captureLog`。
- 进入：设置 → 开发者功能 → 捕获日志。
- 离开：返回。
- 清空：顶栏「清空」→ `EcoConfirm`。
- 「去开启」（未授权时）→ 系统通知监听设置页，**离开 App**。

## 3. 页面骨架

```
Column(fillMaxSize, navigationBarsPadding)
  EcoTopBar(micro="CAPTURE LOG", title="捕获日志", onBack,
            action = rows 非空 ? "清空" : {})
  Column(padding horizontal 22)
    Row(状态点 + captureStatusText + 未授权时 "去开启")
    Row(FilterPill ×4：全部/通知/页面/短信)
    Row("共 N 条（仅保留最近记录）" + "点条目看原文")
  if (rows.isEmpty())
    Box(weight 1f) EcoPane { EcoEmpty("暂无捕获记录") }
    EcoPageNote(底部说明)
  else
    LazyColumn(weight 1f, padding 22, bottom 24)
      itemsIndexed LogRowCard（首尾圆角连成一张卡）
```

## 5. 状态与数据流

### 只读

- `captureRows`：已按筛选过滤后的列表（VM 维护 `captureFilter`）。
- `listenerConnected`：通知监听连接。
- `a11yConnected`：无障碍连接。
- `captureFilter`：`null` / `NOTIFICATION` / `A11Y` / `SMS`。
- `granted = vm.isListenerGranted()`。

### 本地

- `clearAsk`、`expandedId`（同一时间只展开一条）。

### 状态点颜色

- 未授权 → `clay`
- 已授权且已连接 → `jade`
- 已授权未连接 → `amber`

### 行状态

- `queued` → `待确认`（Warn）
- `matchedRule` 非空 → `已识别`（Good）
- 否则 → `未匹配`（Neutral）

### 筛选

点 `FilterPill` → `vm.setCaptureFilter(channel)`；列表由 VM 的 `captureRows` 重算，**不本地过滤**。

### 清空

`EcoConfirm(danger=true)` → `vm.clearCaptureLog()`。

## 6. 交互

| 操作 | 结果 |
| --- | --- |
| 点筛选胶囊 | 切通道 |
| 点行 | 展开/收起快照 |
| 展开后「复制原文」 | 写剪贴板 + `EcoToast("已复制原文")` |
| 顶栏「清空」 | 二次确认 → 清空 |
| 未授权「去开启」 | 跳系统通知监听设置 |
| 返回 | 回开发者功能 |

## 7. 文案

- 顶栏：`CAPTURE LOG` / `捕获日志`；`清空`。
- 状态：`通知监听：已连接；无障碍：已连接`；`已授权（连接状态未知）`；`未授权`；`已连接`/`未连接`；`去开启`。
- 筛选：`全部`、`通知`、`页面`、`短信`。
- 计数：`共 N 条（仅保留最近记录）`、`点条目看原文`。
- 空态：`暂无捕获记录` / `收到通知或打开支付页面后会出现；可按通道筛选查看`。
- 页尾：`仅保留最近记录；点条目展开并复制原文。若长时间无记录，重启手机后重试。`
- 行：通道 `通知`/`页面`/`短信`；状态 `待确认`/`已识别`/`未匹配`；`未命中规则`；`接收 {时间}`。
- 清空确认：`清空捕获日志` / `只清除调试记录，不影响账单与待确认条目。` / `清空`。
- Toast：`已复制原文`。

## 9. 坑与验收

**坑**

1. `captureRows` 已经是筛选后的列表；页面不要再按 `filter` 过滤一次。
2. 顶栏「清空」只在有数据时出现。
3. 行卡片用 `paneShape` 连成一张卡：首行只上圆角、末行只下圆角、中间直角；不要每行都套 `EcoPane`。
4. 同一时间只展开一条（`expandedId` 单值）；不要改成多选展开。
5. 快照区最高 150dp 且内部可滚；长文本不要撑高整行。
6. “去开启”会离开 App 到系统设置；返回后状态由 `ON_RESUME` 刷新（页面本身不额外监听）。
7. 复制格式是给开发排查用的 `channel=.../pkg=...`，不要改成 JSON 或加中文。
8. `navigationBarsPadding()` 在最外层 Column；列表底部 24dp 已够，不要重复加。

**验收**

- [ ] 四种筛选切换正确，计数随筛选变化。
- [ ] 未授权/已授权未连接/已连接三点颜色与文案正确。
- [ ] 点行展开/收起；快照可滚；复制成功有 Toast。
- [ ] 清空有二次确认，清空后显示空态。
- [ ] 空态与非空布局都贴底、不被导航栏遮挡。
- [ ] 1.25 字体下标题/正文两行截断正常，不撑破卡片。
