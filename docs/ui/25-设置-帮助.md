# 25 · 设置 · 帮助

把 `docs/说明/软件说明.md` 重排成随主题变化的原生帮助页：预算口径 → 自动记账（顶部一条推荐口径提示）→ 兼容性。

源码：`app/src/main/java/com/controleco/app/ui/settings/SettingsHelpScreen.kt`（约 330 行）
共享：`SettingsPage`、`SettingsSection`、`SettingsPane`、`SettingsDivider`、`SettingsNote`、`EcoPane`、`EcoIcons`

---

## 1. 路由与入口

- 路由：`settings/help`。
- 进入：设置首页 →「关于」分组 →`帮助`（在「关于易控钱包」行**之上**）。
- 离开：返回。

---

## 2. 文件地图

| 符号 | 作用 |
| --- | --- |
| `SettingsHelpScreen` | 页面与全部文案（帮助内容以 `HelpEntry` 列表内联） |
| `HelpEntry` | 一条说明的数据：`title` / `icon` / `paragraphs` / `showRing` |
| `HelpEntryBlock` | 渲染一个条目：图标 + 标题 + 圆环图（可选）+ 正文 |
| `HelpText` | 正文渲染，把 `**加粗**` 转成 W700 / `ink2` |
| `HelpRingImage` | 首页预算环示意图（`R.drawable.help_budget_ring`） |
| `HelpCallout` | 暖金提示卡（「推荐悬浮窗入账」） |

数据源：`docs/说明/软件说明.md`（原文口径，改文案时同步该文档与本文档）。

## 9. 坑与验收

**坑**

1. 帮助内容以 Compose 常量内联，**没有运行时 Markdown 解析**；改 md 不会自动生效，要同步改这里。
2. `**加粗**` 是成对标记，`HelpText` 按 `**` 切分奇偶段；正文里不要出现落单的 `**`。
3. 正文不要写反引号代码，统一用「」+ `→` 表示界面路径（与全站文案规则一致）。
4. 图片是白底截图，圆角裁切 + 描边后才放进卡片；换深色模式仍按白底显示，不要套 tint。
5. 不要用 `SettingsLazyPage`：整页是纯文本，`SettingsPage` 的 `verticalScroll` 就够。
6. `HelpCallout` 紧跟在 `SettingsSection` 后（分组头底部 9dp 已是间距），不要再叠加 top padding。
