# 25 · 设置 · 帮助

把 `docs/说明/软件说明.md` 重排成随主题变化的原生帮助页：预算口径 → 自动记账（顶部一条推荐口径提示）→ 兼容性。

**版式要点**：不套卡片（条目与图片都直接排在纸面上），分组用 `SettingsSection` 分隔；
原文反引号与 `**加粗**` 两种标记都渲染成**行内底色标注**。

源码：`app/src/main/java/com/controleco/app/ui/settings/SettingsHelpScreen.kt`（约 300 行）
共享：`SettingsPage`、`SettingsSection`、`SettingsNote`、`EcoIcons`

---

## 1. 路由与入口

- 路由：`settings/help`。
- 进入：设置首页 →「关于」分组 →`帮助`（在「关于易控钱包」行**之上**）。
- 离开：返回。

---

## 2. 文件地图

| 符号 | 作用 |
| --- | --- |
| `SettingsHelpScreen` | 页面与全部文案（帮助内容以 `HelpEntry` 列表内联） |
| `HelpEntry` | 一条说明的数据：`title` / `icon` / `paragraphs` / `showRing` |
| `HelpEntryBlock` | 渲染一个条目：图标 + 标题 + 圆环图（可选）+ 多段正文，末尾留 `ENTRY_GAP` |
| `HelpText` | 正文渲染：解析 `term` 与 `**强调**`，套底色 |
| `HelpRingImage` | 首页预算环示意图（`R.drawable.help_budget_ring`），只做圆角裁切 |
| `HelpCallout` | 暖金浅底整段标注（「推荐悬浮窗入账」） |
| `HelpBody` / `HelpTitle` / `ENTRY_GAP` / `INLINE_MARK` | 字号、条目间距、行内标记正则 |

数据源：`docs/说明/软件说明.md`（原文口径，改文案时同步该文档与本文档）。

## 3. 页面骨架

```
SettingsPage(micro="HELP", title="帮助", onBack)
  SettingsSection("预算", "BUDGET")
    HelpEntryBlock 首页      Home      + 预算环图 + 1 段
    HelpEntryBlock 预算计算  Pie       + 3 段
    HelpEntryBlock 每月首日  Calendar  + 1 段
  SettingsSection("自动记账", "CAPTURE")
  HelpCallout（推荐「悬浮窗入账」+ 打开「入账提醒」，暖金浅底整段标注）
    HelpEntryBlock 权限与保活 Shield   + 2 段
    HelpEntryBlock 重复记账   Copy     + 3 段
    HelpEntryBlock 遗漏记账   Warning  + 4 段
    HelpEntryBlock 微信红包   Gift     + 1 段
    HelpEntryBlock 悬浮窗相关 Overlay  + 1 段
  SettingsSection("兼容性", "COMPATIBILITY")
    HelpEntryBlock 银行软件无法使用 Wallet + 1 段
  SettingsNote（"遇到说明之外的问题，请在“设置 → 开发者功能”留存捕获日志后联系作者。"）
```

**没有 `EcoPane` / `SettingsPane`**：帮助页是长文阅读页，卡片会把每段都框起来、打断阅读节奏。

## 9. 坑与验收

**坑**

1. 帮助内容以 Compose 常量内联，**没有运行时 Markdown 解析**；改 md 不会自动生效，要同步改这里。
2. `INLINE_MARK = \*\*(.+?)\*\*|`([^`]+)`` 按 **成对** 匹配；正文里不要出现落单的 `**` 或反引号，否则剩余部分会原样显示。
3. 反引号里的内容会带底色，**不要拿它包整句长文案**（会变成大块色条）；只包界面名、状态词、按键名。
4. 正文不要写反引号代码；界面路径仍用 `设置`-`权限` 这种原文写法（短横线连接，靠底色分段）。
5. 图片是白底截图，只做圆角裁切；换深色模式仍按白底显示，不要套 tint。
6. **不要给条目重新套 `SettingsPane`/`EcoPane`**：本页刻意用「无卡片 + 24dp 间距」做分段，套回卡片会显得拥挤。
7. 不要用 `SettingsLazyPage`：整页是纯文本，`SettingsPage` 的 `verticalScroll` 就够。
8. `HelpCallout` 紧跟在 `SettingsSection` 后（分组头底部 9dp 已是间距），不要再叠加 top padding。
