# 08 · 账户管理

从个人页账户入口、设置 → 账户入口进入。页面是“总资产卡 + 账户列表 + 新增/编辑底部卡”。

源码：`app/src/main/java/com/controleco/app/ui/accounts/AccountsScreen.kt`（约 453 行）

---

## 1. 路由与入口

- 路由：`accounts`。
- 进入：
  - 个人页账户入口（`onOpenAccount`）
  - 设置 → 账户入口 → `账户管理`
- 离开：返回 `popBackStack()`。
- 新增：顶栏 `+`、右下 `EcoSquareFab`、空态提示。
- 编辑：点账户行。

## 5. 状态与数据流

### 只读

- `accounts: List<AccountEntity>`
- `accountBalances: List<AccountBalance>`（`initialBalanceCents`、`signedSumCents`）

### 总资产

```
total = Σ( 期初余额 + signedSumCents )
```

### 行余额

`current = initial + flow`；右侧拆解显示 `期初 ... · 流水 ...`（带显式符号）。

### 本地

- `showEditor`、`editing`、`sheetError`。
- `isDefault = index == 0 && accounts.size > 1`：列表第一个账户标“默认”。

### 保存

`AccountEditorSheet.onSave(id, name, cents, note)` → `vm.saveAccount(...)`：

- 成功：清 error、关 sheet。
- 失败：`sheetError` 显示在 sheet 内。

### 删除

- `onDelete` 仅编辑已有账户时存在。
- 先 `EcoConfirm(danger=true)`；确认后 `vm.deleteAccount(id)`。
- 成功关 sheet；失败 `sheetError`。
- 账户下已有流水时后端会拒绝，sheet 显示错误。

## 7. 文案

- 顶栏：`ACCOUNTS` / `账户管理`；contentDescription `新增账户`。
- 总资产：`TOTAL ASSETS / 本机余额`、`{n} 个账户 · 点账户编辑`。
- 章节：`账户 / ACCOUNTS`。
- 空态：`暂无账户` / `点右下角 + 新增一个账户，余额与流水都记在账户下`。
- 行：`默认`、备注为空时 `无备注` / 默认账户 `新交易默认使用此账户`、`期初 ... · 流水 ...`。
- 页尾：`账户余额 = 期初余额 + 全部收入 − 全部支出。修改期初余额会改变当前余额，不会改动流水；账户下已有流水时无法删除。`
- 编辑 sheet：`新增账户` / `编辑账户`、`账户名称`、`例如：招商银行`、`期初余额`、`0.00`、`可留空 = 0；修改期初余额会改变当前余额，不会改动流水。`、`备注`、`可选，例如：储蓄卡 · 尾号 0921`、`保存`、`取消`、`删除账户`、`账户与余额只保存在本机；删除账户不会影响已入账的流水。`
- 删除确认：`删除账户` / `删除后不可恢复。账户下若已有流水，需要先处理这些账单才能删除。`

## 9. 坑与验收

**坑**

1. **余额口径不变**：`期初 + 全部收入 − 全部支出`。不要改成“当前账户余额字段”。
2. 修改期初余额只影响余额，不改流水；文案必须保留这句。
3. 删除账户不删流水；有流水时删除会被拒绝，错误显示在 sheet 内。
4. 首字标记颜色按账户名稳定取色（`categoryColor`），不是按下标轮询；新增账户不会让旧账户换色。
5. 行首标记没有图标字段，只有首字；不要仿照分类加图标。
6. `EcoSquareFab` 与顶栏 `+` 等价，两个入口都保留。
7. `isDefault` 只在“第一个且账户数 >1”时显示；只有一个账户时不标默认。
8. 列表底部 112dp 是给 FAB 的；改 FAB 位置时同步。
9. sheet 内错误来自 VM（重名、有流水等），不要在前端重复判断覆盖。

**验收**

- [ ] 总资产 = 各账户（期初+流水）之和。
- [ ] 账户行余额与拆解正确，负数变陶土色。
- [ ] 新增/编辑/删除全流程正确，失败错误显示在 sheet。
- [ ] 有流水的账户删除被拒绝并有提示。
- [ ] 空态与 FAB 可用。
- [ ] 1.25 字体下账户名/余额/拆解不裁。
- [ ] 深浅色下总资产卡与行对比正常。
