# 16 · 设置 · 账户入口

设置体系里的“账户”子页。只放两个入口：账户管理、分类管理；不放预算、余额明细或导入。

源码：`app/src/main/java/com/controleco/app/ui/settings/SettingsAccountScreen.kt`（46 行）
共享：`SettingsPage`、`SettingsSection`、`SettingsPane`、`SettingsRow`、`SettingsDivider`

---

## 1. 路由与入口

- 路由：`settings/account`。
- 进入：设置体系 / 个人页“账户”入口（`onOpenAccount`）。
- 离开：
  - 账户管理 → `accounts`
  - 分类管理 → `categories`
  - 返回。

## 9. 坑与验收

**坑**

1. 这里**只放两个入口**；预算、导入、退款显示都不属于本页。
2. 不要给两行加副标题（当前设计就是无副标）。
3. 用 `SettingsPage`，不要再套 `EcoTopBar` 或自己加 padding。
4. 章节不显示编号；本页只有一个分组。

**验收**

- [ ] 两个入口都能到达对应页。
- [ ] 行高、图标、chevron 与其它设置子页一致。
- [ ] 1.25 字体下标题不裁。
- [ ] 返回行为正确。
