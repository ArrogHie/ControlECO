# 23 · 保活引导

开发者功能 → 保活与自启动。设备品牌 hero（服务状态）→ 安卓 13+ 侧载解锁警告 → `01` 电池优化白名单 → `02` 品牌设置步骤。

源码：`app/src/main/java/com/controleco/app/ui/keepalive/KeepAliveScreen.kt`（约 407 行）
数据：`KeepAliveIntents`、`DeviceBrands`、`Brand`、`KeepAliveStep`、`KeepAliveAction`

## 1. 路由与入口

- 路由：`keepAlive`。
- 进入：设置 → 开发者功能 →「保活与自启动」；权限页/关于页的排障文案也会引导到这里。
- 离开：
  - 服务行「去开启」→ 系统通知使用权 / 无障碍设置
  - 警告卡「打开应用信息」→ 本 App 应用信息
  - 「申请忽略」→ 系统电池优化请求
  - 步骤行「打开自启动设置」/「应用信息」→ 对应系统页
  - 返回。

## 5. 状态与数据流

### 只读

- `listenerConnected`、`a11yConnected`。
- `lastCaptureAt`：0 → `尚未收到`。
- `granted = isListenerGranted()`、`a11yEnabled = isA11yEnabled()`。
- `batteryIgnoring = KeepAliveIntents.isIgnoringBatteryOptimizations(context)`。
- `model = Build.MODEL`、`androidVersion = Build.VERSION.RELEASE`。
- `brand = Brand.current()`、`steps = DeviceBrands.stepsFor(brand)`。
- `serviceRunning = connected || a11yConnected`。

### 刷新

`resumeTick` 在 `ON_RESUME` +1；所有 `remember(resumeTick)` 重算（授权、电池、型号/版本）。

### 服务状态

- 通知监听：
  - 已授权且连接 → `已连接`（jade）
  - 已授权未连接 → `已授权（连接未知）`（amber）
  - 未授权 → `未授权`（amber）+ `去开启`
- 无障碍：
  - 已开启且连接 → `已连接`
  - 已开启未连接 → `已开启（连接未知）`
  - 未开启 → `未开启` + `去开启`
- 最近捕获：`formatTimestamp(lastCaptureAt)` 或 `尚未收到`。

### 顶部 pill

- `serviceRunning` → `服务在运行`（Good，带点）
- `granted || a11yEnabled` → `待连接`（Warn，带点）
- 否则 → `未就绪`（Neutral）

### 电池

- 已忽略 → 行标题 `已忽略电池优化` + `已加入`（Good，点）
- 未忽略 → `未忽略电池优化` + `申请忽略` 动作。

### 步骤

- `steps` 来自 `DeviceBrands.stepsFor(brand)`；每步可有 `actions`：
  - `AUTOSTART` → `打开自启动设置` → `openAutostartWithFallback(context, brand)`
  - `APP_INFO` → `应用信息` → `launchAppDetails(context)`

## 9. 坑与验收

**坑**

1. **代码里只有 01 / 02，没有 03 和页尾 note**；文件头注释已过时。不要照注释补一个不存在的“03 更多说明”。
2. 自启动/省电策略多数无法程序检测，所以只能“能查的显示 + 步骤 + 跳转”；不要假装能读出开关状态。
3. `resumeTick` 必须在 `ON_RESUME` 重算；否则从系统页返回电池/授权状态不更新。
4. `serviceRunning` 只看通知连接或无障碍连接，不看 `lastCaptureAt`。
5. 最近捕获没有状态点（`tone=null`），用 `muted`；不要给它加绿点。
6. 电池优化未忽略时显示 `申请忽略`，不是 `去开启`；两者语义不同。
7. 品牌步骤与动作来自数据层；改文案改 `DeviceBrands`，不要在 UI 里写死机型步骤。
8. 底部要用 `ecoBottomContentPadding`；否则内容会被底栏/FAB 压住。
9. 警告卡是 `claySoft`，不是 `amberSoft`；与权限页的琥珀提示带区分。
