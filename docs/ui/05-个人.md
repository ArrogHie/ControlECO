# 05 · 个人

四个 tab 中的 tab 3。它同时是“账本入口页”：预算 hero、月/日预算、待确认、分类/每月首日/设置、底排导入/打赏/主题。没有 FAB。

源码：`app/src/main/java/com/controleco/app/ui/profile/ProfileScreen.kt`（约 1592 行）

---

## 1. 路由与入口

- 路由：`main` tab 3。
- 进入：底部「个人」。
- 离开：
  - hero 金额 → 本月预算 sheet
  - hero 右上铅笔 / 日预算整卡 → 日预算 sheet
  - 月/日分段 → 只切 VM 的 `dailyBudgetMode`，**不切下方瓦片内容**
  - 待确认椭圆 → `pending`
  - 分类卡 → `categories`
  - 每月首日卡 → 滚轮 sheet（`MonthStartSheet`）
  - 设置卡 → `settings`
  - 导入账单 → `settings/import`
  - 打赏 → `RewardDialog`
  - 主题 → `ThemeSheet`
  - GitHub 圆钮 → 系统浏览器打开仓库
- 无再次点击回顶逻辑（个人页没有接 `scrollToTopTick`）。

### BudgetHero

- 197dp 高，非对称圆角 **12/33/12/33**，`heroA/B/C` 渐变，固定深色前景常量 `HERO_MINT / HERO_MINT_SOFT / HERO_INK / HERO_BTN_INK`。
- 顶部：英文眉标 + 账户动作；金额 `HeroAmount`（48/800），点金额开预算 sheet；右上 26dp 铅笔开预算 sheet。
- 6dp 进度轨（白 18% 底，`C3F1CB → 57DBAA` 填充）。
- 底部一行：`已花 X` / `N%` / `剩余 Y`，`RowTrail`。

### BudgetDuo

- 高 161dp；左右间距 9dp。
- 左列 `weight(1f)`：
  - `EcoSegmented("月预算","日预算")`，高 42dp；选中 `ink` 底、`paper` 字。
  - `DailyTile` 占剩余高度；**永远显示 `dailyBudgetCents`**，不随分段变化。
- 右列固定宽 `PENDING_WIDTH = 111dp`，`PendingPill` 跨两行。

### DailyTile

- 圆角 **10/27/10/27**，蓝软渐变 + `rule` 描边，阴影 11dp。
- 整卡可点 → 日预算 sheet。
- 内容：金额 `DailyValue`（31/800）+ `/day`；未设置显示 `未设置` + `/day`。
- 右侧 43dp 铅笔水印，alpha **0.20**，旋转 -8°，**只是装饰**。
- 右下角 `预算管理` 10sp 蓝色文字。

### PendingPill

- 宽 111dp、高占满 161dp；圆角 50（椭圆）。
- 双层环：外层虚线 inset 6，内层实线 inset 18×17。
- 有待确认：陶土浅底 + 收据图标 + `%02d` 数量（`PendingCount` 35/800）+ `待确认`；无待确认：玉绿底 + 对勾 + `待确认`。
- 每 4.5s 末尾摇一下（仅 alert 时）。

### MidRow

- 高 150dp；左分类卡 `weight(1f)`，右列固定 127dp；列间距 10dp，右列两卡间距 8dp。
- 分类卡：圆角 **25/9/25/9**，玉绿渐变，标题 `分类设置` 19sp/790，4 个分类瓦片。
  - 瓦片宽 = `(可用宽 - 5*3)/4`，限制 **30–42dp**；高 **43dp**；圆角 12dp；`glyphScale=0.57f`。
  - 内容 `SpaceEvenly`，padding 9/9/15/14。
- 每月首日卡：80dp，圆角 **12/28/12/28**，蓝色渐变；日历 17dp + `每月首日` 9.5sp + `%02d 日` 21sp + 右下 chevron。
- 设置卡：62dp，圆角 **28/12/28/12**，琥珀渐变；齿轮 18dp + `设置` 16sp + chevron。

### BottomRow

- 高 66dp，间距 9dp；宽度分配：GitHub 63dp / 中间 `weight(1.03f)` / 导入 `weight(1.27f)`。
- 中间列再分两半：打赏 / 主题。
- GitHub：63dp 圆形深墨底 + 链接图标。
- 打赏：陶土渐变胶囊，咖啡 + `打赏` 10.5sp。
- 主题：彩虹渐变胶囊 + 白色画笔 28dp，**没有白色内圆底**。
- 导入：hero 渐变胶囊 + 下载图标 + `导入账单` 12.5sp。

## 5. 状态与数据流

### 只读 Flow

`monthlyBudgetCents`、`homeNetSpent`、`currencySymbol`、`pendingCount`、`monthStartDay`、`dailyBudgetMode`、`dailyBudgetCents`、`categories`。

`spentReady == null` → 整页 `return`（与首页同口径）。

`snapshot = Budget.compute(budget, spent, today, period)`；`period = MonthPeriod.of(today, monthStartDay)`。

### 本地状态（全部是 sheet 开关）

`showBudgetSheet`、`showCurrencySheet`、`showReward`、`showAbout`、`showTheme`、`showDayBudget`、`showMonthStart`。

### 事件

- `onModeChange` → `vm.setDailyBudgetMode(it)`（只改模式，不改 DailyTile 显示）。
- `onManageBudget` → `showDayBudget = true`（整卡/铅笔都是日预算）。
- hero 金额/铅笔 → `showBudgetSheet = true`（按当前模式编辑月/日预算）。
- `onOpenPending` / `onOpenCategories` / `onOpenSettings` / `onOpenImport`：走路由。
- `onOpenMonthStart` → `showMonthStart`。
- `onPick`（主题）→ `AccentThemeStore.set(context, accent)`；主题立即生效。
- 货币 → `vm.setCurrencySymbol`。
- 月起始日 → `vm.setMonthStartDay`。

## 8. 坑与验收

**坑**

1. **日预算瓦片永远显示日预算**，即使分段选“月预算”。这是用户明确要求；不要“修正”成跟随分段。
2. 日预算整卡都可点；右侧 43dp 铅笔是水印（alpha .20），**不要给它单独加点击**，否则会出现两个点击区。
3. 主题按钮只负责主题；不要再把“更多/关于/货币”塞回它。`MoreSection` / `MoreSheet` / `AboutDialog` / `AboutTile` / `ImportOrb` 都是遗留死代码。
4. `showAbout` 在 `ProfileScreen` 里从未被设为 true，所以 `AboutDialog` 不可达；关于页入口现在在设置里。
5. 分类卡瓦片宽度随可用宽度自适应（30–42dp），高度固定 43dp；不要写死 42dp，窄屏会挤。
6. `CategoryCard` 必须 `SpaceEvenly`，标题不要贴顶、图标不要贴底。
7. 底排宽度是 `63 / 1.03fr / 1.27fr`；改成等分会破坏原型比例。
8. 月起始日滚轮在卡内，`MonthStartSheet` 里 `EcoSheet` 必须 `scrollable=false`，否则滚轮手势被 sheet 抢走。
9. hero 前景色是固定的深色卡配色，不要改用 `eco.ink`（浅色主题下会变深，深色主题下会变白，都会破坏对比）。
10. `spentReady == null` 整页 `return`，不要先画 0。

**验收**

- [ ] 月/日分段只改 VM 模式，日预算瓦片数值不变。
- [ ] 日预算整卡、hero 金额、hero 铅笔分别打开正确的 sheet。
- [ ] 待确认 0 / >0 两种配色和数量显示正确，点按进 `pending`。
- [ ] 分类卡 4 个瓦片在窄屏/1.25 字体下仍排得下。
- [ ] 每月首日卡点击/长按都能操作滚轮，sheet 不抢手势。
- [ ] 主题切换立即全局生效；主题按钮不再打开“更多”。
- [ ] 底排三个入口（GitHub/打赏/导入）都能到达。
- [ ] 1.25 字体下 hero、双列、中排、底排不裁字。
- [ ] 深浅色下 hero 与各渐变卡的前景可读。
