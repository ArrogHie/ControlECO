# 04 · 统计

四个 tab 中的 tab 2。结构：共享结余封面 → 周期工具条 → `01` 支出节奏柱状图 → `02` 分类预算圆环（吸顶）→ 预算对比清单。没有 FAB。

源码：`app/src/main/java/com/controleco/app/ui/stats/StatsScreen.kt`（约 995 行）
共享：`ui/transactions/BalanceCard.kt`、`ui/transactions/CoverStyleStore.kt`、`ui/common/PeriodControls.kt`

---

## 1. 路由与入口

- 路由：`main` tab 2。
- 进入：底部「统计」。
- 离开：本页不导航；周期/筛选均在本页状态内。
- 再次点「统计」tab → `scrollToTopTick` +1，`LazyColumn` 回顶。

## 3. 页面骨架

```
Column(fillMaxSize)
  EcoTopBar(micro="INSIGHTS / {MON}", title="统计", action="{年} / {月}")
  LazyColumn(
    state,
    pointerInput 空白点击 -> 取消圆环选中,
    contentPadding = PaddingValues(bottom = ecoBottomContentPadding(extra=180.dp))
  )
    item cover:  Box(padding 22/6) BalanceCard(showEdit=false)
    item toolbar: StatsToolbar
    item trendHead: EcoSectionHead("01", "每日支出"/"月度支出", "DAILY"/"MONTHLY")
    item trend: TrendCard
    stickyHeader donutSticky: Column(background paper)
        EcoSectionHead("02", "分类预算与占比", "BUDGET / ACTUAL")
        DonutCard
    item ratio: RatioCard
  if (showPicker) PeriodPickerSheet
```

`extra = 180.dp` 是**有意留的滚动余量**：让 `02` 圆环能真正吸顶；滚到最底会看到一段空白，这是已知取舍。

## 4. 关键尺寸 / 字号

### 封面

- 与账单页完全同一 `BalanceCard`：满宽 × **150dp**，圆角 22dp。
- 外层 `padding(horizontal=22, vertical=6)`。
- `showEdit=false`：统计页不显示换图按钮；`onOpenImageSettings = {}`。
- 切换月/年由封面左上分段触发 `vm.setPeriodMode`。

### 工具条

- 高 **45dp**，左右 22dp，上 4 / 下 2。
- 周期文字：13.5sp/800，负字距 -0.5；副标 `ACCOUNTING MONTH/YEAR` 7.5sp，字距 0.9。
- 左右箭头 27×28，圆角 8dp，图标 13dp。
- 右侧月/年 `EcoSegmented`：宽 88dp，高 30dp，`small=true`。

### 01 支出节奏

- 卡：`EcoPane`，左右 22dp，圆角 20dp。
- 头部：`支出节奏` 12.5sp + 右侧读数标签 9sp + 金额 15sp。
- 分隔线 1dp；下方图表：
  - 空态高 155dp：`本月还没有支出` / `记一笔后这里会出现柱状图`。
  - 正常 `ExpenseBarChart` 高 **200dp**。
- 选中柱：月视角按“日”，年视角按“月”；当前周期默认选今天/当前月，历史周期默认选支出最高的一根。

### 02 圆环

- `stickyHeader` 外层 `background(c.paper)`，避免吸顶时透出内容。
- `EcoSectionHead` 左右 22dp。
- `DonutCard`：`EcoPane` 左右 22dp，圆角 20dp。
- 圆环：`CategoryDonut(ringSize=150.dp, showCenterLabels=false, singleRing=true)`。
- 左右两列各 `weight(1f)`：
  - 左：`实际支出` / 选中分类名（8sp），金额 16sp（宽限 84dp），占比 9sp。
  - 右：`预算`，金额 16sp（宽限 84dp），占比 9sp。
- 未选中时左显示“实际支出”与本期总支出，右显示总预算。
- 空态：`暂无分类数据`。

### 预算对比

- `EcoPane` 左右 22dp，上 14dp，圆角 20dp。
- 头部：`预算对比` + 右侧 `实际 / 预算`。
- 行高 `heightIn(min=42dp)`，左右 14dp，上下 12dp。
- 左侧 9dp 竖色条 + 分类名 + 实际金额 + 占比；第二行预算金额 + 预算占比。
- 选中某分类时其它行 alpha **0.46**；选中行底色 `blueWash`。
- 空态：`暂无分类预算`。

## 5. 状态与数据流

### 只读 Flow

| 状态 | 用途 |
| --- | --- |
| `month` | 当前周期 |
| `periodMode` | 月/年 |
| `currentAccountingMonth` | 判断是否当前周期 |
| `monthStartDay` | 会计月起始日 |
| `periodTotals` | 收入/支出合计 |
| `periodCategorySums` | 本期分类实际支出 |
| `periodRows` | 本期流水（柱状图） |
| `categoryBudgets` | 分类预算 |
| `categories` | 分类名/图标/类型 |
| 封面 5 个 Flow | 与账单共享 |

`rows / totals / byCategory` 任一为 null → 整页 `return`。

### 派生

- `expense` / `income` / `balance`：从 `periodTotals` 取。
- `isCurrentPeriod`：月模式比 `YearMonth`，年模式比年份。
- `bars`：`ChartMath.monthBars(rows, month, monthStartDay)` 或 `yearBars(rows, month)`。
- `defaultBarIndex`：当前周期取今天/当前月；历史周期取支出最高柱。
- `selectedBar`：页面状态，`remember(bars)` 重置。
- `slices`：`ChartMath.mergeSlices(实际分类支出, 分类预算)`；年模式预算 ×12。
- `sliceColors`：与分类图标同色（自定义颜色优先，否则从 palette 选“离已用色最远”）。
- `ratioRows`：`buildRatioRows(...)`；年模式预算 ×12。
- `selectedSlice`：圆环/清单共享的选中分类；点页面空白取消。

### 交互

- 左右箭头：`vm.prevPeriod()` / `nextPeriod()`。
- 点周期文字：`PeriodPickerSheet`。
- 月/年分段：`vm.setPeriodMode(...)`。
- 点柱/滑柱：`selectedBar`；卡片头部读数跟随。
- 点环/图例行：选中分类；再点空白取消。
- 在 `LazyColumn` 外层 `pointerInput` 检测空白点击，清空选中；环和行自己消费点击。

## 8. 坑与验收

**坑**

1. **只有一个圆环**。历史上的双环/环心数字/图例都已废弃；`CategoryDonut` 必须 `singleRing=true`、`showCenterLabels=false`。不要再加第二个环。
2. 底部 `extra=180.dp` 是为了吸顶预留的滚动余量，不是 bug；删掉会让 `02` 在短列表上无法吸顶。
3. `stickyHeader` 的背景必须是 `c.paper`，否则吸顶时会透出下方内容。
4. 年模式的预算要 **×12**（切片和对比都是），漏乘会让占比全错。
5. 圆环颜色必须与分类图标同色；不要按 `slices` 下标轮询 palette。
6. 点空白取消选中依赖 `LazyColumn` 外层 `pointerInput`；给卡片加全屏 `clickable` 会截断它。
7. `ConclusionCard` / `StatsSummaryLine` / `RatioSide` 等是死代码；改页面时不要误以为它们在渲染。
8. 统计页复用账单封面状态；在账单页换图后统计页立即变，不要另存一份。
9. `PeriodPickerSheet` 的年选择只改年份、保留当前月；沿用 `vm.setMonth` 的语义。

**验收**

- [ ] 月/年切换后，工具条、章节标题、柱状图分组、预算 ×12 全部正确。
- [ ] 圆环只有一个、无中心数字、颜色与分类图标一致。
- [ ] 点环/点行选中，左右金额与占比切换；点空白取消。
- [ ] `02` 滚动时能吸顶，且吸顶背景不透内容。
- [ ] 底部 180dp 余量保留；滚到底的空白可接受。
- [ ] 空数据（无支出、无分类预算）文案正确。
- [ ] 封面与账单同步，统计页没有换图按钮。
- [ ] 1.25 字体下工具条、圆环两侧金额、对比行不裁。
- [ ] 再次点「统计」tab 回顶。
