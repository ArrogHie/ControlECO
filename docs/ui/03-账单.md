# 03 · 账单

四个 tab 中的 tab 1。结构是：顶栏（搜索 + 设置两个图标）→ 结余封面 → 周期/筛选工具条（排序 + 分类筛选 + 全部/支出/收入）→ 笔数 → 流水列表（时间排序按天分组、金额排序平铺；右侧自绘滚动条）→ 批量/删除 sheet。FAB 打开快速记账。

源码：

- `app/src/main/java/com/controleco/app/ui/transactions/TransactionListScreen.kt`
- `app/src/main/java/com/controleco/app/ui/transactions/BalanceCard.kt`（结余封面，统计页复用）
- `app/src/main/java/com/controleco/app/ui/transactions/CardImageEditor.kt`（封面图片平移/缩放/旋转）
- `app/src/main/java/com/controleco/app/ui/transactions/BillFilters.kt`（类型/分类/金额/商户筛选 + 排序纯逻辑，搜索页共用）
- `app/src/main/java/com/controleco/app/ui/transactions/CategoryFilterSheet.kt`（分类多选 sheet，搜索页共用）
- `app/src/main/java/com/controleco/app/ui/transactions/BillSortSheet.kt`（排序方式 sheet，搜索页共用）

## 1. 路由与入口

- 路由：`main` tab 1。
- 进入：底部「账单」。
- 离开：
  - 点行 → `edit/{txId}`
  - FAB → `quickAdd`
  - 右上放大镜 → `search`（搜索页，见 [26-搜索](26-搜索.md)）
  - 右上图片按钮 → 本页 `CoverSheet`
  - 点日期头 → `DayJumpDialog`（只滚动定位，不导航；**金额排序平铺时没有日期头，跳日不可用**）
- 再次点「账单」tab → `scrollToTopTick` +1，列表回到顶部（页面记 `lastReenterTick`，只在 tick 增大时回顶；从别的 tab 切回来保持原滚动位置）。

## 3. 页面骨架

```
Column(fillMaxSize)
  EcoTopBar(micro="LEDGER / {年}", title="账单", action=搜索按钮 + 设置按钮)
  BalanceCard(150dp, padding horizontal 22)
  BillToolbar(45dp)
  if (selecting) BatchBar
  Text("{n} 笔", 右对齐, 9sp)
  when
    rows 为空 -> BillEmpty("本周期还没有记录")
    filtered 为空且分类筛选生效 -> BillEmpty("本周期没有所选分类的记录")
    filtered 为空 -> BillEmpty("没有{筛选}记录")
    else -> Box(weight 1f)
      LazyColumn(contentPadding bottom=96, end=10)
        // sort.groupedByDay（时间排序）：
        stickyHeader DayHeader
        items BillListItem（无日期前缀）
        // 金额排序（平铺，没有日期头）：
        items BillListItem(showDate=true)
      ListScrollbar(align CenterEnd, 宽 18)
  // overlay: FAB（外壳）
  // sheets/dialogs: CoverSheet / BatchSheet / CategoryFilterSheet / BillSortSheet / PeriodPickerSheet / DayJumpDialog / EcoConfirm
```

**统计页复用同一张卡**，但 `showEdit=false`，且不提供换图入口（换图只在账单页）。

### 工具条 `BillToolbar`

- 高 **45dp**，左右 16dp。
- 左/右箭头 26dp 圆形，图标 14dp。
- 中间周期：宽 **78dp**，标题 13.5sp/800，下面 `MONTH`/`YEAR` 7.5sp。
- 右侧（从左到右）：`ToolbarIconAction(Sort)` → `ToolbarIconAction(Filter)` → `EcoFilterStrip`（`全部 / 支出 / 收入`）→ 更多按钮（`EcoIcons.More`，打开 `BatchSheet`）；
  图标按钮之间 6dp，筛选条与更多之间 4dp。
- **`ToolbarIconAction`**：26dp 圆形热区、图标 14dp；生效（非默认排序 / 有分类筛选）时图标由 `muted` 转 `blueDeep`，
  并在热区右上角点一个 5dp 主色圆点——否则用户看到被收窄或重排过的列表会以为账单丢了。
- **横向预算（390dp 屏，fontScale 1.25）**：箭头 26 + 周期 78 + 箭头 26 + 排序 26 + 6 + 筛选 26 + 6 + 筛选条 ≈ 123 + 4 + 更多 26 ≈ **347dp**，
  可用宽度 390 − 32 = **358dp**，余量约 11dp。为了让排序按钮挤进来，这里把周期从 82dp 收到 78dp、
  给 `EcoFilterStrip` 传 `itemPadding = 8.dp`（默认 10dp，只影响本页）。**这一行已经满了，不要再加按钮**；
  要加就先算这笔账，或把入口挪进 sheet。

### 列表

- 行：`heightIn(min = 56.dp)`，左右 20dp，上下 8dp。
- 分类图标：`EcoCategoryTile(size=30.dp, radius=10.dp, bare=true)`。
- 标题 12.5sp/600；副标 9.5sp；备注 9.5sp；金额 `BillAmount` 13.5sp/800。
- 支出金额 `ink`，收入 `jade`，支出不带 `-`（`Money.formatSignedCurrency` 传负值会带符号，注意现有实现）。
- 退款标记：`退款`（jade）/`已退`（amber），8sp。
- 预算口径小标（只在支出行）：`不计预算`（muted）/`AA 3`（blueDeep），8sp，紧跟退款标记之后；
  文案与优先级由 `BudgetShare.tag` 决定（同时勾选时只显示「不计预算」）。
- 行间 `HorizontalDivider` 左侧缩进 55dp（收在 `BillListItem` 里）。
- 日期头：吸顶，显示日期与当日收支；点击打开跳日。
- 列表底部 padding 96dp；右侧 10dp 给滚动条。
- **两种列表形态**：
  - 时间排序（`TIME_DESC` / `TIME_ASC`）：按天分组、吸顶日期头，行内小行是「HH:mm　分类」；
  - 金额排序（`AMOUNT_DESC` / `AMOUNT_ASC`）：**平铺**、无日期头，行内小行补日期「M月d日 HH:mm　分类」
    （`BillRow(showDate = true)`）——没有日期头时，行内不写日期就看不出这笔是哪天的。
  - 两种形态的分页不同：按天用 `pageDays`（整天推进），平铺用 `sorted.take(loadedLimit)`；触底加 `PAGE_ROWS` 的逻辑共用。

### 批量条

- 虚线顶边，左右 22dp，上下 6dp；「已选 N」+ 全选/删除/取消。

### 滚动条

- 4dp 宽拇指，idle alpha .24，active .55；拖动按像素比例直接滚列表。

## 5. 状态与数据流

### 只读 / VM

| 状态 | 用途 |
| --- | --- |
| `rows`（`periodRows`） | 当前周期流水，null = 未就绪 |
| `month` | 当前会计月 |
| `mode` | `MONTH` / `YEAR` |
| `monthStartDay` | 会计月起始日 |
| `pendingJump` | 从待确认/通知跳转到的日期（VM 状态） |
| 封面：`cardImageUri/cardImage/cardTransform/cardImageColor/cardImageLuminance` | 与统计共享 |
| `CoverStyleStore.current` | 封面底色 |

### 本地状态

- `filter: TxFilter`（ALL/EXPENSE/INCOME）。`rememberSaveable`，进详情页再返回保持原筛选。
- `categoryIds: Set<Long>`：分类多选筛选，空 = 不筛。`rememberSaveable(stateSaver = CategoryIdSetSaver)`（`Set<Long>` 本身不可存，走 `LongArray` 中转），
  与 `filter` 是 **AND**；同样跨「进详情页再返回」「切 tab」保留，**切周期不清空**。
- `sort: BillSort`（TIME_DESC 默认 / TIME_ASC / AMOUNT_DESC / AMOUNT_ASC）。`rememberSaveable`；
  `groupedByDay` 决定列表是「按天分组」还是「金额平铺」。
- `showFilterSheet` / `showSortSheet`：分类筛选 sheet / 排序 sheet。
- `selecting: Boolean`、`selected: Set<Long>`。
- `loadedLimit`：分页深度（按天分组时按“天”、金额平铺时按“行”），首批 `FIRST_PAGE_ROWS`，触底每次 +`PAGE_ROWS`。`rememberSaveable`，
  返回时保留已排到的深度（否则恢复出来的 index 会被只有首页的内容夹到页尾）。
- `lastPeriodKey` / `lastFilterKey`：回顶判定用的“上一次生效的键”，`rememberSaveable`（`lastFilterKey` 现在是 `billListKey(filter, sort)`）。
- `showCoverSheet`、`showBatchSheet`、`showPicker`、`showImageEditor`、`jumpTarget`。
- `confirm: DeleteConfirm?`（标题、正文、动作）。
- `listState: LazyListState`。
- `scrollToTopTick`（入参）。

### 数据流

1. `rowsReady` 为 null → 整页 `return`。
2. `filtered = applyBillFilters(rowsReady, filter, categoryIds)`（先类型后分类，见 `BillFilters.kt`）。
3. `sorted = sortBills(filtered, sort)`；默认 `TIME_DESC` 原样返回（DAO 已经是 `timestamp DESC, id DESC`）。
4. `byDay = sort.groupedByDay`：
   - true → `grouped = groupRowsByDay(sorted)`，`pageDays(allDays, grouped, loadedLimit)` → `shownDays`；
   - false → `shownRows = sorted.take(loadedLimit)`，`grouped` 为空。
5. `hasMore` 两种形态各自算；`LaunchedEffect(listState, sorted)`：最后可见项 ≥ 总数−3 时 `loadedLimit += PAGE_ROWS`。
6. `pendingJump`：找到 ≤ 目标日的最近一天，必要时先扩 `loadedLimit`，再滚到对应 header（金额平铺时没有 header，该 effect 直接返回）。
7. `LaunchedEffect(month, mode)` / `LaunchedEffect(filter, sort)`：**键真的变了**才清空选择、重置分页、滚到顶部
   （判定走 `BillListMemory.kt` 的 `billPeriodKey` / `shouldResetBillList`）。这两个 effect 在每次重新进入
   组合时都会重跑，从详情页返回、切 tab 回来都算，所以不能无条件回顶。
8. `scrollToTopTick`：比较 `lastReenterTick`，仅 tick 增大时 `animateScrollToItem(0)`。

> 分类筛选**没有**自己的重置 effect：它不像类型筛选/排序那样改变“看哪一批、按什么顺序看”，只把列表收窄；
> 回顶由第 7 条里的 `billListKey(filter, sort)` 负责，改分类筛选本身不回顶（用户是在 sheet 里点选的，位置保持更自然）。

### 删除

- 单笔：批量勾选后删除，或编辑页删除。
- 本周期/本年/全部：先 `countTransactionsInRange` / `countAllTransactions`，用真实条数生成确认文案，再删。
- 所有删除都走 `EcoConfirm(danger=true)`，文案含「删除后不可恢复」。

## 7. 文案

- 顶栏 micro：`LEDGER / 2026`；标题 `账单`。
- 工具条：`2026.10` + `MONTH`；年模式 `2026` + `YEAR`。
- 笔数：`N 笔`。
- 空态：
  - `本周期还没有记录` / `点右下角「记账」补一笔，或到「个人」页导入账单。`
  - `本周期没有支出记录` / `切回「全部」看看其它记录。`
  - `本周期没有所选分类的记录` / `换个分类，或点工具条上的筛选按钮重置。`（分类筛选生效时优先于上一条）
- 分类筛选 sheet：`按分类筛选`、副标 `可多选`（已选时 `已选 N 个分类`）、分组 `支出` / `收入`、按钮 `重置` / `应用筛选`；
  没有分类时正文 `还没有分类，先到「分类管理」里添加。`
- 排序 sheet：`排序方式`，副标默认不显示（非默认排序时 `当前：{选项}`）；四行标题 / 副标：
  `时间（新→旧）` / `按天分组，最近的在前`、`时间（旧→新）` / `按天分组，最早的在前`、
  `金额（大→小）` / `不分天，整个周期从大到小`、`金额（小→大）` / `不分天，整个周期从小到大`；当前项右侧打勾。
- 批量：`批量管理`、`删除本周期全部记录…`、`删除本年全部记录…`、`删除全部记录…`，副标说明范围。
- 删除确认：`将删除 N 条记录，删除后不可恢复。`
- 封面：`更换结余卡背景`、`从相册选择图片…`、`调整图片…`、`移除图片`、`有图片时优先用图片；移除后回到当前底色。调整可平移、缩放、旋转。`

## 9. 坑与验收

**坑**

1. `rowsReady == null` 时整页 `return`（避免先空后跳）；不要改成显示空态。
2. **分类 logo 必须 `bare=true`**（30dp；无底色无描边，图形满格）。带底色会变成“彩色小方块”，与设计不符。
3. 列表分页：时间排序按“天”（不切开某一天），金额排序按“行”；新增/删除后 `loadedLimit` 可能失效，
   需保持 `LaunchedEffect(month, mode)` / `LaunchedEffect(filter, sort)` 的重置逻辑。
4. 右侧滚动条 overlay 在列表上，列表 `contentPadding(end=10)` 必须保留，否则会压住金额。
5. 批量全选是 `rowsReady.map { it.id }`（当前周期全部），不是 `filtered`；改筛选语义时要想清楚
   ——**加了分类筛选、排序之后这条依然成立**（全选仍是整周期，不跟着筛选/排序走）。
6. 删除范围用会计月/会计年（`MonthPeriod`），不是自然月；不要改成 `YearMonth` 直接算。
7. 封面与统计共享同一个 VM 状态：在账单页换图，统计页会同步；这是预期。
8. `DayJumpDialog` 用 M3 `DatePickerDialog`（未做 ECO 换肤），属于已知例外；不要为了统一把它改坏。
9. **返回详情页后不能回顶**（曾经的 bug：点进某笔账单返回，列表跳回顶端）。`rememberLazyListState`
   是 `rememberSaveable`，NavHost 的 `SaveableStateProvider` 本来就能恢复位置；踩的是另一半——
   重置 effect 每次重新进入组合都会重跑，无条件 `scrollToItem(0)` 在恢复后的同一帧把位置抹掉。
   所以：回顶只能由 `shouldResetBillList(上次键, 本次键)` 把关（`BillListMemory.kt`）；
   `filter` / `sort` / `categoryIds` / `loadedLimit` / 两个 key 必须是 `rememberSaveable`，否则恢复的 index 站不住。
   不要在 `ON_RESUME` / 首帧无条件 `scrollToItem(0)`。
10. `categoryIds` 是 `Set<Long>`，**不能直接 `rememberSaveable`**（Bundle 存不了 Set），必须带 `stateSaver = CategoryIdSetSaver`；
    漏了会在恢复时抛 `IllegalArgumentException`（进详情页返回就崩）。
11. 分类筛选与类型筛选是 **AND**，不是替代关系：`applyBillFilters` 里先类型后分类，别把两者写成二选一。
12. `DayHeader` / `BillRow` / `BillListItem` / `BillEmpty` 已改为 `internal` 供搜索页复用：改它们等于同时改搜索页，
    加参数时给默认值（如 `onClickDay` / `showDate`）以免搜索页出现“点了没反应”的空 ripple 或缺日期。
13. **金额排序必须平铺**：把金额排序塞进“按天分组”里只会变成“天内排序”，跨天的金额排名就没了；
    平铺时**必须** `showDate = true`，否则行里只有 `HH:mm`，看不出是哪天的账。
14. 金额排序**不改**每行的方向语义：`amountCents` 收支都存正数（方向靠 `type`），所以排序按金额绝对值即可；
    不要在排序里对收入取负、否则“金额大→小”会把支出全排到收入前面。
15. 工具条一行已经排满（390dp / fontScale 1.25 余量约 11dp）：再加图标前先按第 4 节的宽度账核算，
    不要靠 `weight` 或压缩间距硬塞——`Row` 溢出时最后一个按钮会被推到屏幕外（看起来像“更多按钮消失了”）。
16. 跳日在金额平铺形态下**不可用**（没有日期头可点），这是刻意取舍；不要把 `DayJumpDialog` 挂到别处找补。
