# 17 · 设置 · 账单导入

账单导入的设置子页：导入入口 + 微信/支付宝导出教程 + “显示退款记录”开关。

源码：`app/src/main/java/com/controleco/app/ui/settings/SettingsImportScreen.kt`（79 行）
共享：`SettingsPage`、`SettingsSection`、`SettingsPane`、`SettingsRow`、`SettingsSwitchRow`、`SettingsNote`

---

## 1. 路由与入口

- 路由：`settings/import`。
- 进入：个人页底排「导入账单」。
- 离开：
  - 选择账单文件 → `import`
  - 返回。


## 4. 关键尺寸 / 字号

- `SettingsPage`：顶栏 64dp，内容 22dp，底部 32dp。
- 教程行 `minHeight = 66.dp`，`subtitleMaxLines = 3`。
- 普通行最小 54dp；图标槽 34dp（`bare`，无底色/描边）；副标 9.5sp/15。
- 开关行沿用 `SettingsSwitchRow`（`EcoSwitch`）。

---

## 5. 状态与数据流

- 唯一状态：`showRefunds` ← `vm.showRefunds`。
- 开关 → `vm.setShowRefunds(it)`，立即生效到账单/统计/退款关联。
- 导入入口只回调 `onImport`，不在此页解析文件。

## 7. 文案

- 顶栏：`IMPORT` / `账单导入`。
- 01：`导入 / IMPORT`；`选择账单文件`、`微信 xlsx / 支付宝 CSV`。
- 02：`导出账单 / HOW TO`。
  - 微信：`我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单，用途选「用于个人对账」，xlsx 会发送到邮箱。`
  - 支付宝：`我的 → 账单 → 右上角「…」 → 开具交易流水证明，用途选「用于个人对账」，CSV 会发送到邮箱。`
- 03：`显示 / DISPLAY`；`显示退款记录`。

## 9. 坑与验收

**坑**

1. “选择账单文件”只负责导航，真正的文件选择器在 `ImportScreen`；不要在这里 `launch`。
2. 教程必须保留平台差异（微信 xlsx / 支付宝 CSV），不要合并成一句。
3. `subtitleMaxLines=3` 与 `minHeight=66dp` 是配套的；改小会截断教程。
4. “显示退款记录”只影响显示与汇总，不影响退款入库。
5. 用 `SettingsPage`，不要嵌套 LazyColumn。

**验收**

- [ ] 导入入口能进入导入页。
- [ ] 两段教程完整显示（1.25 字体下不截断）。
- [ ] 退款开关持久化，切换后账单/统计行为同步。
- [ ] 三组章节编号与 aside 正确。
