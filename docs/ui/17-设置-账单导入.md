# 17 · 设置 · 账单导入

账单导入的设置子页：导入入口 + 微信/支付宝导出教程。

> 「显示退款记录」开关已删除：退款记录永远入库、永远显示；退款收入永远计入收入，
> 被退款的原支出仍留在流水里（带「已退」角标），但**不再计入支出**。详见 [12-退款关联](12-退款关联.md)。

源码：`app/src/main/java/com/controleco/app/ui/settings/SettingsImportScreen.kt`（65 行）
共享：`SettingsPage`、`SettingsSection`、`SettingsPane`、`SettingsRow`、`SettingsNote`

---

## 1. 路由与入口

- 路由：`settings/import`。
- 进入：个人页底排「导入账单」。
- 离开：
  - 选择账单文件 → `import`
  - 返回。

---

```

  SettingsSection("01","导入","IMPORT")

    SettingsRow("支付宝", 3 行教程, App, blue, minHeight=66)
```

## 5. 状态与数据流

- 本页**没有状态**：不持有 ViewModel 引用，两个参数只有 `onBack` / `onImport`。
- 导入入口只回调 `onImport`，不在此页解析文件。

| --- | --- |

| 返回 | 回个人页 |

---

## 7. 文案

- 顶栏：`IMPORT` / `账单导入`。
- 01：`导入 / IMPORT`；`选择账单文件`、`微信 xlsx / 支付宝 CSV`。
- 02：`导出账单 / HOW TO`。
  - 微信：`我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单，用途选「用于个人对账」，xlsx 会发送到邮箱。`
  - 支付宝：`我的 → 账单 → 右上角「…」 → 开具交易流水证明，用途选「用于个人对账」，CSV 会发送到邮箱。`

## 9. 坑与验收

**坑**

1. “选择账单文件”只负责导航，真正的文件选择器在 `ImportScreen`；不要在这里 `launch`。
2. 教程必须保留平台差异（微信 xlsx / 支付宝 CSV），不要合并成一句。
3. `subtitleMaxLines=3` 与 `minHeight=66dp` 是配套的；改小会截断教程。
4. **不要再加回退款显示开关**：退款永远显示，不存在“显示/隐藏”这个维度了。
5. 用 `SettingsPage`，不要嵌套 LazyColumn。

**验收**

- [ ] 导入入口能进入导入页。
- [ ] 两段教程完整显示（1.25 字体下不截断）。
- [ ] 页面上没有退款相关开关。
- [ ] 两组章节标题与 aside 正确。
