# 02 · 首页

首页是四个 tab 中的 tab 0。它没有列表，而是一张可翻转的“预算/分类/资产”三面卡片；底部只有模式圆点，没有其它按钮（设置入口在顶栏右上）。

源码：`app/src/main/java/com/controleco/app/ui/home/HomeScreen.kt`（约 1218 行，单文件）

---

## 1. 路由与入口

- 路由：`main`，`MainScaffold` tab 0。
- 进入：启动默认页；点底部「首页」。
- 离开：
  - 右上「设置」胶囊 → `settings`
  - 分类模式右上管理按钮 → `categories`
  - 点卡片/横滑 → 只在本页三种模式间翻转，不导航
  - 底部 FAB → `quickAdd`（由外壳提供，不在本页）
- 再次点「首页」tab：不滚动（首页无滚动），`reenterTick` 不传给首页。

## 3. 页面骨架（从上到下）

```
Column(fillMaxSize)
  EcoTopBar(
    micro = "{年} / {MON} 账本",
    title = "{中文月份}",
    low = modeLow,                    // " / 预算" | " / 分类" | " / 资产"
    action = EcoSettingsPill
  )
  Box(weight(1f), padding(horizontal=22))
    Box(fillMaxSize, graphicsLayer rotationY, pointerInput 点击/横滑)
      when(mode)
        0 -> Budget 存在 ? ModeRemaining : ModeNeedsBudget("预算")
        1 -> Budget 存在 ? ModeCategories : ModeNeedsBudget("分类预算")
        2 -> ModeSpentAndDeposit
    if (mode == 1 && Budget 存在)
      ManageButton(align TopEnd, top=10)
  ModeDots(current, onSelect)
  Spacer(ecoBottomContentPadding(extra=4))
```

预算 sheet 在页面末尾条件渲染（不占布局）。

## 4. 关键尺寸 / 字号 / 颜色

### 顶栏

- 主页面 72dp；标题 `EcoType.TopTitle`（28/800）；`low` 用 `EcoType.TopLow`（28/500，`muted`）。
- micro：`{year} / {MMM} 账本`，英文月份大写。

### 模式 0：预算环

| 元素 | 规格 |
| --- | --- |
| 环直径 | `min(maxWidth * 0.84, 306dp)`，最小 176dp |
| 主环粗 | 以 320 为基准 `34u`（u = 实际直径/320） |
| 液面 | 斜向线性渐变 `toneHi/tone/toneHi/tone`，从 -90° 起；每次进入首页从 0 播 1.1s 动画 |
| 时间细环 | 半径 `r - 27.5u`，粗 5.5u，蓝色 sweep；每次进入 1.3s |
| 外描边/内亮线 | `r+18.3u` / `r-17.3u` |
| 凹槽阴影 | 内壁 `r-0.22*stroke` 压暗、外壁 `r+0.24*stroke` 提亮：空轨看起来凹下去，液面像填满凹槽 |
| 虚线装饰 | `r-37u`，dash 1u/7u |
| 中心 | 标签 `本月剩余` + `EcoCountUpMoney(MeterMoney, widthLimit=size*0.65, min=21sp)` + 百分比 + 蓝色「N 天」文字（无胶囊底、无小圆点） |
| 垂直布局 | 上 `weight 1f`，环，`weight 1f`，TodayCard，下 `weight .28f`（环在顶部与今日剩余之间居中） |

色调：`OK → jade`、`MID → amber`、`LOW → clay`；`toneHi` 对应 `jadeHi/amberHi/clayHi`。

### TodayCard

- 宽 `fillMaxWidth(0.77f)`，高 **108dp**；**无底色、无边框、无投影**，文字直接落在页面背景上。
- 标签：`本日剩余` / 超支时 `今日已超支`（`AssetLabel 10sp`）。
- 金额：`TodayAmount`（47/700），超支显示 `-todayLeft` 并 `clay`；剩余 ≤ 建议日预算 25% 用 `amber`。
- 右上 16dp 星光图标，呼吸 + 轻微旋转；底部 92×8dp 装饰线。

### 模式 1：分类

- 顶部「分类剩余」`AssetLabel 10sp` + `CatTotal`（38/800，宽限 250dp）。
- `MonthProgress`：30dp 日历图标（`EcoIconTile`，`bare = true`）+ 「本月进度」14sp + `已过/总天数` 13sp + 6dp 进度条 + 两端 8.5sp 说明。
- 分类条：
  - 容器：`bars.size >= 6` 时可滚动（`verticalScroll`），否则 `SpaceEvenly`；左右无额外 padding。
  - 行高：普通 ≥70dp、compact ≥64dp、dense ≥58dp。
  - 图标：27/25/23dp，圆角 `size*0.33`；合成条「未设预算分类」用 `EcoIconTile(Spark, amber)`。**两者都 `bare = true`**（无底色无描边，图形满格）。
  - 标题：14.5/14/13.5sp，800。
  - 右侧剩余：`CatAmount` 16.5sp（dense 14.5），色：超支 `clay`、比例 <35% `amber`、否则 `jade`；
    合成条残值为 0 时**也显示金额**（剩余 = −已花，`clay`），不再显示「未设预算」。
  - 进度条 9dp，填充为分类色渐变；超支 `clayHi→clay`；合成条残值 0 时按超支处理（**画满 + `clay`**）。
  - 底部「已花 X」/「预算 Y」9sp（dense 8sp）；残值 0 时右侧为「未设预算」。
- 空态：`还没有分类预算。到「个人 → 分类」为支出分类设定预算后...`。
- 管理按钮：35dp 圆形、`surface`、`rule` 描边、15dp 铅笔。

### 模式 2：资产

- 上下两段各 `weight(1f)`，中间 26dp 分隔行（两侧 1dp 线 + 中间 5dp 空心圆）。
- 每段：`AssetChart` 铺满背景 + 纸色径向渐变遮罩 + 居中标签（`AssetLabel 11sp`、5dp 点）+ `AssetAmount`（48/800，宽限 320dp）。
- 「本月已花」恒 `ink`；「总存款」正数 `blue`、负数 `clay`。
- 折线是**固定路径**（`AssetChart` 内两组 points，viewBox 390×330），不来自数据；面积 alpha `.44/.16/.01`，线 alpha `.34/.40`、粗 1.2/1.3dp（只比渐变深一点，不抢视觉）。

### 模式圆点

- 行高 37dp，居中；选中宽 25dp，未选 7dp，高 7dp，圆角全圆。
- 选中渐变 `jade → blue`；未选 `ruleStrong`。

## 5. 状态与数据流

### 只读 Flow

| 状态 | 来源 | 用途 |
| --- | --- | --- |
| `monthlyBudgetCents` | VM | 月预算 |
| `homeSpent` | VM | 本月支出 = **计入预算的支出**：Σ(未被标「已退款」的支出)，不计入预算算 0、AA 按 金额 ÷ n（null = 未就绪） |
| `homeTodaySpent` | VM | 今日支出（同口径） |
| `categoryBudgets` | VM | 分类预算 map |
| `homeCategorySums` | VM | 本月分类「计入预算」金额：同口径按分类分组，**各分类之和恒等于本月支出**，不可能为负 |
| `categories` | VM | 分类实体（图标/类型） |
| `totalDepositCents` | VM | 总存款 |
| `monthStartDay` | VM | 会计月起始日 |
| `dailyBudgetMode` | VM | 当前预算模式（月/日） |
| `dailyBudgetCents` | VM | 日预算 |
| `homePeriodRows` | VM | 资产页趋势（`buildHomeTrend` 使用） |

`spentReady / todaySpentReady / sumsReady / depositReady` 任一为 `null` → **整页不画**，直接 `return`，避免先显示 0。

### 本地状态

- `showBudgetSheet`：预算 sheet。
- `todayState`：`LocalDate.now()`；`ON_RESUME` 时刷新并 `vm.refreshToday()`（跨天回来不显示昨天）。
- `mode`：`rememberSaveable` 0–2。
- `flip: Animatable<Float>`：Y 轴翻转角度。
- `dragging` / `dragRotation`：拖动中的角度。
- `snapshot`：`Budget.compute(...)`，在 `remember(budget, spent, today, todaySpent, period, dailyBudgetCents)` 中计算。
- `bars`：`buildCategoryBars(...)`。
- `trend`：`buildHomeTrend(...)`。

### 事件

- 点卡片/点圆点 → `flipTo(target)`：150ms 转到 ±90°，换模式，snap 到反方向，再 150ms 回 0；`rememberReducedMotion()` 为真时直接换模式。
- 横滑：拖动角度按 `90 / (width * 0.3)` 映射，限制 ±90°；松手看速度（≥ 1.1 屏宽/秒）或角度（≥ 45°）决定翻页，否则回弹。
- 预算 sheet 保存：`dailyBudgetMode ? vm.setDailyBudget : vm.setMonthlyBudget`。
- 分类管理 → `onOpenCategories`。
- 右上齿轮 → `onOpenSettings`。

### 纯逻辑口径

- `buildCategoryBars`：只取**有预算**的支出分类（没设预算的分类不单独成条）。
  合成条「未设预算分类」（`NO_BUDGET_BUCKET_NAME`）预算 = 月预算 − 已分配预算（**残值 < 0 按 0**），
  支出 = 总支出 − 已分配支出（就是没设预算的那些分类）。
  **出现条件：残值 > 0 或该支出 > 0** —— 分类预算之和 ≥ 月预算时，只要这些分类花过钱仍会出条（剩余为负），
  否则这部分支出在分类模式上没有任何落点。无预算基准时 `ratio` 取占位值 `NO_BUDGET_RATIO = −1`（避免 0 除），
  所以合成条排在正常分类之前、但不越过超支超过 100% 的分类。按 `ratio` 升序排序（最紧张在前）。
  **支出用 `homeCategorySums`**（计入预算的金额：不计入预算算 0、AA 按 金额 ÷ n），与「本月已花」同口径；
  分类之和恒等于本月支出，不做任何退款扣减。
  与分类管理里那个**真实分类**「其他」不是一回事：真实「其他」设了预算就自己占一条，两者可并存、不再重名。
- 头部「分类剩余」= `Budget.compute` 的 `remainingCents` = 月预算 − 本月支出，**不是各条剩余之和**：
  有合成条时两者恒等；分类预算之和 ≥ 月预算时头部会大于各条之和（合成条按 0 预算算），这是预期。
- 首页是**预算口径**：账单勾了「不计入预算」时，首页本月支出会小于统计页「实际支出」
  （统计页只把 AA 折算为 m ÷ n，「不计入预算」仍按全额，见 [04-统计](04-统计.md)）。
  这是设计口径，不是数据不一致。
- `buildHomeTrend`：资产页折线数据（当前图表并不使用，保留口径/历史）。
- `CategoryRingData` 是旧模式①口径，保留给单测；新 UI 用 `CategoryBarData`，两者规则一致（含合成条）。

不要新增“欢迎语”“财务建议”等长文案；首页是读数页。

## 9. 坑与验收

**坑**

1. 首页在数据未就绪时 `return`，整页空白是**有意**的；不要改成显示 0。
2. `todayState` 必须在 `ON_RESUME` 刷新，否则跨天/后台回来「今日」是旧的。
3. 环径只受宽度限制（`min(maxWidth*0.84, 306)`），不要改回按高度缩放，小屏会缩得很难看。
4. `AssetChart` 是固定路径，**不要**接真实数据“优化”——原型就是装饰曲线。
5. `ModeCategories` 在 `bars.size >= 6` 时自己开 `verticalScroll`；不要再套外层滚动，会冲突。
6. `EcoArrival` 每行延迟 `70 + index*55`，行多时最后几行出现较慢；这是预期。
7. `EcoCountUpMoney` 的 `widthLimit` 必须小于可用宽度，否则金额会溢出；改卡片宽度时同步改。
8. 翻转期间 `flip.isRunning` 会忽略新手势；不要去掉这个保护，否则模式会错乱。
9. 低动态模式（`rememberReducedMotion`）只对翻转生效，其它呼吸动画不强制关闭。
10. 「未设预算分类」是**合成条**，不是分类：预算 = 月预算残值（残值 < 0 按 0），支出 = 总支出 − 已分配支出。
    残值为 0 时它没有进度基准：进度条**画满 + `clay`**（无预算却有支出 = 超支，空轨会让人误以为没花钱），
    `ratio` 取 `NO_BUDGET_RATIO = −1` 占位，
    所以「分类预算之和 ≥ 月预算」时头部「分类剩余」会大于各条剩余之和——不要试图"对齐"这两个数。
11. 别把合成条与分类管理里那个**真实分类**「其他」混为一谈：真实「其他」设了预算会自己占一条（可编辑、可删），
    合成条只读、名字固定。删分类时流水改挂的是真实「其他」，与合成条无关。

**验收**

- [ ] 三种模式都能点、滑切换，圆点同步。
- [ ] 未设预算显示空态 + 按钮能开 sheet。
- [ ] 分类预算 0 / 超支 / 正常三种颜色正确。
- [ ] 只给部分分类设预算时，没设预算分类的支出落进「未设预算分类」条，不会凭空消失。
- [ ] 分类预算之和 ≥ 月预算且这些分类花过钱时，该条仍出现、剩余为负（`clay`）、**进度条画满**；没花过钱则不出条。
- [ ] 真实分类「其他」设了预算时，与「未设预算分类」两条并存、名称不重复。
- [ ] 资产页正负存款颜色正确。
- [ ] 1.25 字体下今日卡金额、分类条标题、资产金额不裁。
- [ ] 底部 FAB 不遮挡模式圆点（`ecoBottomContentPadding` 生效）。
- [ ] 跨天回前台，今日剩余刷新。
- [ ] 深色模式下环/卡片/文字对比度正常。
