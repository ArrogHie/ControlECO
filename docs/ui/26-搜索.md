# 26 · 搜索

账单页右上角放大镜进入的子页。按 **商户 + 金额** 搜当前周期内的账单，另外可叠加 **类型**（全部/支出/收入）、**分类多选** 与 **排序**；结果行样式与账单页完全一致，点行进编辑页。

**范围就是当前会计周期**（与账单页同一个 `vm.periodRows`，月模式 = 当月、年模式 = 本年），不跨月跨年，也没有额外的日期筛选——要找别的月份的账单，先回账单页切周期。

源码：

- `app/src/main/java/com/controleco/app/ui/transactions/TransactionSearchScreen.kt`
- `app/src/main/java/com/controleco/app/ui/transactions/BillFilters.kt`（匹配规则 + 排序纯函数）
- `app/src/main/java/com/controleco/app/ui/transactions/CategoryFilterSheet.kt` / `BillSortSheet.kt`（账单页共用）
- `TransactionListScreen.kt` 里的 `DayHeader` / `BillListItem` / `BillRow` / `BillEmpty` / `ToolbarIconAction` / `pageDays`（复用）

## 1. 路由与入口

- 路由：`search`（`AppNav.kt` 的 `NavHost`）。
- 进入：账单页右上角放大镜（`EcoTopBar` 的 `action` 里，位于设置齿轮左侧）。
- 离开：
  - 返回按钮 / 系统返回 → `popBackStack()`，回到账单页
  - 点结果行 → `edit/{txId}`
- 不是通知/快捷方式路由，不需要进 `CaptureCenter.ROUTE_*` 的 `when` 分支。

## 5. 状态与数据流

### 只读 / VM

| 状态 | 用途 |
| --- | --- |
| `periodRows` | 当前周期流水，null = 未就绪（直接 `return`，与账单页同一约定） |
| `month` / `periodMode` | 顶栏与空态里的周期文案（`periodLabel`） |
| `categories` | 分类 sheet 的分组数据 |

### 本地状态（全部 `rememberSaveable`）

| 状态 | 说明 |
| --- | --- |
| `keyword` | 商户关键字 |
| `amountMode` / `exactText` / `minText` / `maxText` | 金额条件；两种模式各自保留输入，切换回来还在 |
| `typeFilter` | `TxFilter` |
| `categoryIds` | `Set<Long>`，配 `CategoryIdSetSaver` |
| `sort` | `BillSort`，默认 `TIME_DESC`；决定结果按天分组还是平铺 |
| `loadedLimit` | 分页深度（按天分组时按“天”、金额平铺时按“行”） |
| `lastQueryKey` | 回顶判定用的“上一次生效的条件键”（含排序） |
| `autoFocused` | 只在首次进入时自动聚焦（从编辑页返回不再弹键盘） |
| `showFilterSheet` / `showSortSheet` | 分类 / 排序 sheet（不需要跨进程保留，用 `remember`） |

### 数据流

1. `rowsReady == null` → 整页 `return`。
2. `query = BillSearchQuery(keyword, amountQueryOf(...), typeFilter, categoryIds)`。
3. `results = searchBills(rowsReady, query)`：条件没填任何一项时返回**空列表**（页面显示引导文案，不展示周期全量）。
4. `sorted = sortBills(results, sort)`；`byDay = sort.groupedByDay`：
   - true → `grouped` + `pageDays`（吸顶日期头）；
   - false → `shownRows = sorted.take(loadedLimit)`（平铺 + 行内日期）。
   触底 `loadedLimit += PAGE_ROWS`（同账单页）。
5. `LaunchedEffect(queryKey)`：`queryKey = billSearchKey(query, sort)`，只有 `shouldResetBillList(上次, 本次)` 为 true 才重置分页并 `scrollToItem(0)`
   ——本 effect 在「从编辑页返回」时也会重跑，无条件回顶会抹掉刚恢复的位置（同账单页的坑，见 `BillListMemory.kt`）。

## 6. 交互与跳转

| 操作 | 结果 |
| --- | --- |
| 输入商户 / 金额 | 实时过滤（无“搜索”按钮） |
| 精确 / 范围 | 切换金额条件形式；精确只看「金额」，范围只看「最小 / 最大」 |
| 类型筛选条 | 改 `typeFilter` |
| 点排序按钮 | `BillSortSheet`，点一行即生效并关 sheet；改排序会回顶并重置分页 |
| 点「分类 N」 | `CategoryFilterSheet`，`应用筛选` 后写回 `categoryIds` |
| 点结果行 | `onEditTransaction(id)` → `edit/{txId}` |
| 返回 | `popBackStack()`；再次进入时条件、排序与滚动位置按 `rememberSaveable` 恢复 |
| 键盘 | 首次进入自动聚焦商户框；根节点 `.imePadding()`，键盘可见时**去掉** `navigationBarsPadding`（否则底部多出一截，同快速记账/编辑页） |

## 7. 文案

- 顶栏：micro `SEARCH / 2026.10`（年模式 `SEARCH / 2026`）；标题 `搜索`。
- 占位：`搜索商户名`、`金额`、`最小`、`最大`。
- 笔数：`N 笔`（只在填了条件时显示）。
- 空态：
  - `当前周期还没有记录` / `回账单页点右下角「记账」补一笔，或到「个人」页导入账单。`（整个周期为空时优先，避免用户以为搜索坏了）
  - `输入商户或金额开始搜索` / `范围是当前周期（2026.10），也可以只用类型、分类筛选。`
  - `没有符合条件的记录` / `换个商户名、金额或筛选条件试试。`
- 分类 / 排序 sheet 文案见 [03-账单](03-账单.md) 第 7 节（同一组件）。

## 9. 坑与验收

**坑**

1. **不填条件不展示全量**：`searchBills` 在 `!query.isActive` 时返回空列表是刻意的——否则搜索页与账单页完全重复。
   要改这个行为，得同时想清楚首屏 200+ 行的滚动性能。
2. `categoryIds` 必须走 `CategoryIdSetSaver`，否则 `rememberSaveable` 恢复时崩（Bundle 存不了 `Set`）。
3. 回顶只能由 `shouldResetBillList` 把关（同账单页第 9 条坑）；这里用的是 `billSearchKey(query, sort)`，条件与排序都没变就不许回顶。
4. 自动聚焦要 `autoFocused` 把关：`LaunchedEffect(Unit)` 在从编辑页返回时会重跑，无条件 `requestFocus()` 会让键盘再弹一次。
5. 结果列表**不要**再套一层 `verticalScroll`；整页只有 `LazyColumn` 一个滚动容器（表头是固定区）。
6. 金额输入用 `KeyboardType.Decimal`；`Money.parseCents` 解析失败一律当“没填”，不要弹错误提示打断输入。
7. 搜索页是子页，**没有**底栏与 FAB：根节点 `.imePadding()` + 键盘不可见时 `navigationBarsPadding()`，列表底部留白 24dp；
   不要套 `ecoBottomContentPadding()`（那是主页面口径）。漏掉 `imePadding()` 会让键盘盖住结果列表的最后几行。
8. 排序与账单页是**两套独立状态**（各自 `rememberSaveable`）：搜索页改排序不会改账单页的排序，反之亦然。
   这是刻意的——搜索是临时动作，不该覆盖用户在账单页的阅读顺序。
9. 金额排序同样要平铺 + `showDate = true`（同账单页坑 13）：搜索结果跨多天，行内没日期就看不出是哪天。

**验收**

- [ ] 从账单页放大镜进入；返回后账单页筛选、排序与滚动位置不变。
- [ ] 商户搜索：子串命中、忽略大小写与空白；空关键字不算条件。
- [ ] 金额精确：`12.5` / `12.50` / `¥12.5` / `-12.5` 都能命中 12.50 的那笔。
- [ ] 金额范围：只填最小 / 只填最大 / 两端都填 / 填反 都符合预期；非法输入不报错、不限制。
- [ ] 类型 + 分类 + 商户 + 金额四项 AND 正确。
- [ ] 排序四项都生效；金额排序平铺且行内有日期，时间排序有日期头；改排序回顶、重置分页。
- [ ] 点结果行进编辑页，返回后条件、排序与滚动位置保留（不回顶）。
- [ ] 三种空态文案正确（周期全空 / 未填条件 / 无匹配）；未填条件时不展示全量列表。
- [ ] 首次进入自动聚焦弹键盘；从编辑页返回不重复弹。
- [ ] 键盘弹起时列表不被遮挡；滚动到底最后一行完整可见。
- [ ] 1.25 字体下金额行（精确/范围）不换行、不裁字；深色模式与 7 套主题下描边/选中态正常。
