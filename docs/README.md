## 维护约定

1. 以实际调用链、SQL 和纯函数为依据；源码注释也可能保留旧口径，不能单凭注释更新文档。
2. 数值规则集中维护在《金额与预算计算》，采集／合并／入账流程见《自动记账捕获机制》，应用识别细节见《自动记账逐应用解析规则》；页面文档引用专题，避免复制多套公式。
3. 区分“已有实现”“已有自动测试”“真机验证”，不把包名列入监听目录等同于识别已适配。
4. 改业务规则时同步专题和相关测试；历史材料保留原意。存在意图不明的差异时先确认，不用文档替代码决定新行为。
